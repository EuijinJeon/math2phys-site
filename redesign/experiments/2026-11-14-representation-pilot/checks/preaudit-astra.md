# 유한 tree representation pilot 사전 정확성 감사

2026-11-14. 독립 감사 1회. PROTOCOL.md, questions.md, answer-key.md, candidates/B.md·C.md를 읽고 `redesign/source/sections/trees.tex`와 대조했다. 후보·문항·정답은 직접 수정하지 않았다. 이 파일만 작성했다. 별도 독자 응답이나 성과는 보지 않았다.

**판정: 아래 Q5(e) 보정이 반영된 현재 문안은 이 소규모 시험의 정확성 gate를 통과한다.** 최초 문안에는 원문이 보장하는 충분조건과 조건의 필요성을 혼동할 수 있는 중요한 문항 문제가 1건 있었다. 작성자에게 전달한 뒤 문항·정답·B/C 부록의 실제 수정 반영을 확인했다. 그 밖에 시험을 막을 수학 오류는 발견하지 못했다. 이는 범위 밖의 P7 전체 증명이나 RPC 대응을 검증했다는 뜻이 아니다.

## 중요 지적 1건 — Q5(e)의 논리적 범위 (보정 완료)

최초 Q5(e)는 떨어진 branching vertex만 선택하면 추가 조건 없이 실제 비율 `Σ|c_E|/|J_sep|`가 L-uniform인지 묻고, 정답은 거짓이며 `m_d≥η>0`이 필요하다고 썼다. 그러나 원문 trees.tex 393–415는 그 조건 아래의 **충분조건**을 제시한다. 증명 449–455는 j≥2 인자에 `|(m_d−jm_{d+1})|≥η`를 적용한다. 이 논증을 조건 없이 적용할 수 없다는 사실이 실제 비율의 발산이나 η 조건의 필요성을 증명하지는 않는다.

정답에 있던 “d=0에서 고차 branching 인자에 추가 δ가 생김”도 단독으로는 반례가 아니다. 예를 들어 old tree가 anchor path 하나이고 k=2이며 anchor와 두 color가 모두 root에서 갈라지도록 처방하면 허용 history의 계수는 `(-δ)(-2δ)=2δ²`, `|J_sep|=2δ²`여서 실제 비율은 1이다. 이 예는 무조건적 일반 명제를 증명하지도 반증하지도 않지만, 작은 분모만으로 발산을 결론 낼 수 없음을 보여 준다.

작성자는 Q5(e)를 “**이 문서에 제시된 δ^{b_sep} 절댓값 계수 한계와 J 비교 논증만으로** 추가 조건 없이 비율의 L-uniform bound가 보장된다”로 제한했다. 정답 역시 해당 비교 논증의 적용 불가를 설명하고 실제 발산이나 필요성 주장이 아니라고 명시했다. B/C 공통 부록의 “때만”은 “조건 아래”로 변경되었다. 수정된 questions.md 18, answer-key.md 27, B.md 89, C.md 84를 직접 확인했다. 수정 후에는 원문 증명의 보장 범위를 묻는 유효한 문항이다.

## 핵심 수학 검산

### C의 signed importance sampling

원문 trees.tex 180–202에서 unprotected old 선택의 계수는 +1, fresh 선택의 계수는 γβ다. 204–219의 망원 합으로 `Σβ(−γβ)=n`이므로 `M=n+u>0`이다. 따라서 매 step에서 `p(z)=|w(z)|/M`, multiplier `w(z)/p(z)=sign(w(z))M`이며, 현재 tree에 의존하는 조건부 확률을 곱하면

`P(h)B_h = ∏_r p(z_r|h_{<r}) · ∏_r [w(z_r)/p(z_r|h_{<r})] = ∏_r w(z_r)=c_h`.

C.md 47–51의 항등식은 정확하다. proposal은 tree 형상·보호 상태에만 의존하며 최종 path 변수는 원래 kernel로 별도 샘플한다. 유한 history 합의 재표현이고 c_h를 양의 확률로 취급하지 않는다. 원문 자체에 sampler가 있다는 주장을 하지 않고 직접 유도된 추가 representation이라고 구별한 것도 타당하다.

### 고정 q,k에서 second moment

C.md 55의 경계는 올바르다. 초기 leaf 수 q≥1, k≥1, 유한 L, 초기 보호집합 C⊆Leaves(T), 유계 G와 D_j를 고정하면 각 단계 `n≤q+k`, `u≤q`이므로 `|B_h|≤(2q+k)^k`다. path 변수까지 실제로 한 번 샘플한 estimator Z에도

`E|Z|² ≤ (2q+k)^{2k} ||G||∞² ∏_j ||D_j||∞² < ∞`

가 성립한다. 조건부 tree 평균을 정확히 계산한 C의 표시식에도 같은 경계가 성립한다. 이 부등식은 고정 norm 경계 아래 L에 의존하지 않지만, 전체 삽입 함수의 해석적 경계와는 다른 진술이다. 상대분산·효율성·무계 observable까지 주장하지 않으므로 과장은 없다. k=0은 빈 history와 B=1로 별도 해석하면 된다.

### 임의 protected set

B/C의 일반 C는 원문보다 강한 무근거 일반화가 아니다. trees.tex 180–183이 이미 임의 집합 C와 parameter-independent G를 정의하고 192–202가 각 보호 leaf에서의 상쇄를 증명한다. 단일 anchor는 298–303에서 이 rule의 특수 사례로 택한다. 따라서 Q2와 C의 u 갱신 규칙은 정당하다. C는 집합이므로 같은 leaf의 A 인자를 중복 상쇄하는 경우는 포함하지 않는다.

## 문항·정답·rubric

- **Q1:** μ=1/2, Z=1+μt₁+t₂. 독립 세 leaf의 밀도에서 `F=[μ(1+t₂)+t₁]²/Z³`. 첫 미분의 두 old 기여는 각각 1/2, fresh 기여는 −3/8로 합 5/8. 둘째 D₂=1 방향은 old-first에서 (n,u)=(3,1), fresh-first에서 (4,2)이므로 두 경우 모두 다음 계수 합은 −2. mixed derivative는 −5/4. 답안 및 6점 배점은 맞다. 서로 다른 매개변수를 한 번씩 미분하므로 별도 factorial이 없다. 원문 근거는 98–103, 180–202, 278–303.
- **Q2:** `U=(μ+t)/(1+μt)³`, `U′(0)=1−3μ²=1/4`. old c만 직접 선택 가능하며 기여 +1, root fresh의 **계수 자체는 γ=−3**, 기대값을 곱한 기여는 −3/4다. 정답의 표기는 압축되어 있으나 이 둘을 구별해 채점하면 문제가 없다. 4점 배점은 맞다.
- **Q3:** 내부 γ는 root −0.4, depth1의 ab −1.2와 c −0.5, depth2의 세 unary 각각 −0.3이다. 합 −3, Q root 확률 2/15. 실제 상수 방향 미분은 −1이고 fresh 합만은 −3이다. 정답과 배점은 맞다. 원문 근거는 95, 204–219.
- **Q4:** D=1이면 log Y₀=log(1+t), canceled expectation=(1+t)^{-1}이므로 3차 도함수/계수는 각각 (2,1/3), (−6,−1). 정답이 anchor-only tree의 fresh factorial 설명과 일반 old tree의 상쇄를 구별했으므로 맞다. 원문 근거는 107–110, 241–256, 278–303.
- **Q5(a):** 현재 문구는 “unary vertex의 기여를 버리고 나머지 vertex의 **기존 γ만** 합산”이라고 명시한다. unary γ=m_d−m_{d+1}<0이므로 거짓이다. trees.tex 29–39와 204–208에 근거하며, 460–462의 형상 서술용 unary 축약과도 혼동하지 않는다. 최신 문항은 이 모호성을 해결했다.
- **Q5(b,c,d,f):** 원문과 부합한다. 특히 (d)는 제시된 fixed-depth analytic bound로부터 depth uniformity를 추론할 수 있는지를 묻는다. 근거는 35–39, 173–176, 259–303 및 서두 11–12. P7 전체·물리 pure-state/RPC 동일시는 이 감사 범위 밖이다.
- **Q6:** 선형성을 이용해 `V(t)=F[H₀](t)+t₁F[H₁](t)`로 쓰면 `∂₁∂₂V(0)=L₁₂[H₀]+L₂[H₁]`. 교차항은 한 번이며 2배나 2!이 없다. 예시에서는 `V=t₁/(1+t₂+μt₁)`로 mixed derivative −1. 정답과 4점 배점은 맞다. bounded fixed H₀/H₁ 각각에 원문 278–303을 적용하고 ordinary product rule을 쓰는 신규 유도다.

## 경미한 주의 — 수정 필수 아님

Q4(iii)의 “history 가중치에 k!이 나타남”을 임의 old tree의 **각 개별 history**가 동일한 factorial weight를 가진다는 뜻으로 읽으면 틀린다. 현재 정답은 anchor-only 예시와 일반 old tree의 상쇄를 구별한다. 독자가 일반 old tree에서 합산·상쇄로 설명해도 정답으로 인정해야 한다. Q2에서 −3은 fresh 계수, −3/4는 기여라는 구별도 유지하면 된다.

PROTOCOL은 추가 수식·예제 노출 차이와 작은 표본을 이미 인정한다. 본 감사는 정확성 점검일 뿐 B/C의 독해 성과나 무힌트 representation 발견 능력을 판정하지 않는다. 이 감사 후 추가 확장 없이 정해진 독자 시험으로 진행할 수 있다.
