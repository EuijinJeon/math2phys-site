# 유한 tree representation 소규모 시험 — 사전 고정 protocol

2026-11-14. 작성·실행 책임: GPT-6.1 Sol. 사용자 승인 범위: 새 실험 폴더만 작성, 기존 자료 수정·commit·push·게시 없음.

## 질문과 범위

- 가설 A: object→representation→공유 rule→derivation으로 다시 쓰면 독자가 새로운 계산·조건 경계·재구성을 더 잘 수행하는가?
- 가설 B: 이런 유용한 representation을 하네스가 무힌트로 발견할 수 있는가? **이번 시험은 검증하지 않는다.** B/C 후보 방향은 사전에 제공되었다. 시험 결과를 발견 능력으로 해석하지 않는다.
- 범위는 현행 L2 §6.1–6.2①의 유한 tree 미분 계산이다. §6 전체 또는 P7의 Palm·극한 증명, 분야 독립 일반성은 검증하지 않는다.
- A: 현행 L2의 해당 범위를 그대로 발췌. B: first variation/protected-leaf rule 중심 재구성. C: 동일 rule의 정확한 signed-tree importance sampling 재표현. C는 RPC와의 동일시를 주장하지 않는다.
- 모든 후보에 동일한 계수 한계/사용 맥락 부록과 동일 질문을 붙인다. A의 링크는 원문 그대로 보존하나 독자에게 외부 접근을 금지한다. B/C에도 근거 경로를 제공하되 열지 않게 한다.

## 독자와 배정

물리 배경(statistical mechanics, expectation·미분·Taylor 급수에 익숙함)을 가진 모의 독자. gpt-6-luna와 gpt-6.1-sol 각각 A/B/C를 별도 신규 세션에서 읽는다(총 6회, 각 cell n=1). 같은 세션 재사용 없음. reader는 packet 하나만 읽고 응답 하나만 작성한다. 다른 파일·웹·다른 후보·원문·답안·이 대화는 금지한다. 이 제한은 파일 권한 격리가 아니라 지시적 격리이며 완전한 보안 경계가 아니다. 도구 흔적과 자기보고로 준수 여부를 남긴다.

작성자 자신이 채점하지 않도록, 모델/후보명을 가린 응답 사본을 별도 독립 채점자에게 준다. 신규 응답 전 Astra가 후보 B/C와 정답을 원문 대조해 감사한다. 허용되는 수정은 독자 전 건전성 보정뿐이고 기록한다. 응답 후 후보·질문·정답을 고치지 않는다. 채점 해석 조정이 생기면 원점수와 함께 기록한다.

## 측정과 판정

Q1(6), Q2(4), Q3(5), Q4(3), Q5(6), Q6(4): 총 28점. Q1–Q3은 본문 예와 다른 observable·leaf 수·보호집합·비균등 격자의 계산/전이(15점). Q4 factorial 재구성(3점), Q5 유효 범위(6점), Q6 매개변수 의존 observable의 product rule 재구성(4점). 자기 평가는 성과 지표가 아니다. 본문 표를 복사하는 것만으로 Q1/2/6 답이 나오지 않는다.

기술적 gate: 후보에 원문보다 강한 주장이 없어야 한다. 정확성 gate를 통과한 후보끼리만 비교한다. 각 모델 내 B−A, C−A 차이를 보고하며 두 모델 평균은 기술 통계에 한한다. 최소 효과량/유의성·일반적 승리/모델 우열 주장 없음. 두 모델 모두 후보가 A보다 2점 이상 개선되고 심각한 경계 오류가 늘지 않으면 이 국소 실험의 '후속 시험 가치' 신호로 부른다. 모두 만점이면 천장 효과로 판별 실패라고 쓴다. 한 모델에서만 개선되면 불일치로 보고한다.

## 통제와 남는 혼입

질문·답안·독자 지시 동일, 모델 내 독립 세션. 후보 길이/예제 개수/추가 식/기호/순서가 완전히 같지 않다. 실제 문자 수와 예제 개수, 핵심 노출 차이를 manifest에 기록한다. 특히 B는 일반 보호집합을 명시하고 C는 sampler까지 명시하므로 '배열만의 인과 효과'를 분리할 수 없다. A는 현행 일부 발췌이므로 현행 전체 사이트 접근 성능을 대표하지 않는다. reader의 배경 지식 사용을 제거할 수 없다. 실행 순서는 모델별 A/B/C이나 각 세션은 신규이므로 기억 순서 효과는 제한되고 시간/서비스 차이는 남는다. 샘플 작음, seed·reasoning effort 완전 통제 불가, 토큰/금전 비용 정밀 측정 불가.

## 중단·완료 기준

대규모 benchmark로 확장하지 않는다. 1회 사전 감사, 6회 독자, 독립 채점, 수치 검산, 오류와 제한을 포함한 REPORT.md로 종료한다. 독자 후 맞춤 재작성·재응시를 하지 않는다.
