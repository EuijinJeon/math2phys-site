# 미완결 표시와 edge 축약

2026-11-14. 수학적 자료 `graphs/move4.json`을 바꾸지 않고 생성기와 보기의 틀을 수정했다.

## 상태 표시

- 내부 node는 국소 완결·미완결·미평가를 명시한다. 색 외에도 문구와 테두리 모양으로 구별한다.
- 입력 edge 누락은 node의 경고와 패널에서 출발·도착 id까지 표시한다. 연결되지 않은 원본 진술을 참고로 읽을 수 있어도 전달된 내용으로 취급하지 않는다.
- 하위 증명의 완결 개수를 바깥 vertex 상태와 함께 표시한다. `첫 변분`은 **내부 3/3 완결 · 외곽 미완결**, 이유는 **XO→D2 입력 edge 없음**이다.
- 생성 로그와 지도 상단에 완결·미완결·미평가·입력 누락·edge 내용 미작성 수를 표시한다. 지도 개요의 미완결 목록에서 해당 node를 선택할 수 있다.
- top의 R2/R3/R4 입력 누락도 새로 드러났다. 이번에는 그 증명을 수정하거나 status를 자동 승격하지 않았다.
- 이 진단은 구조와 명시적 완결 선언을 함께 보여 주며 수학적 자동 인증은 아니다. 기존 check.py의 오류 0과 전체 증명 완결을 동일시하지 않는다.

## edge 식별

- 기본은 `e4 · 첫 변분`처럼 고정된 짧은 ID와 핵심어. 긴 수식·대입식은 지도 위에 반복하지 않는다.
- 핵심어를 끄면 ID만 남는다. `?`는 내용 미작성, `!`는 열린 연결이다.
- 선택하면 전체 진술과 원래 ID, 양 끝 node의 상태를 따로 보여 준다. edge 내용이 완결이라는 이유로 양 끝 vertex가 완결인 것처럼 표시하던 문구를 제거했다.
- `viewer/edge-labels.json`의 명시적 대응을 사용한다. 배열 순서와 무관하게 ID를 유지하고 지도 안의 중복 ID는 생성 오류로 처리한다. 지도 사이의 같은 ID는 `diff/e4`처럼 지도 경로로 구별한다.
- 라벨 위치는 node와 앞선 라벨을 덜 가리는 후보를 선택한다. 임의 graph에 대한 무겹침 보장은 아니다.

## 검증

표시 회귀 시험 **10개 통과**: 첫 변분의 미연결 경계, 잘못된 완결 선언, 내부 완결의 자동 승격 방지, 열린 edge의 상위 상태 전파, 유도 없는 완결 선언, 외부 입력의 구분, 기존 완결 vertex 보존, edge 재정렬 후 ID 유지, edge/vertex 상태 분리, 원자 상세의 축약·원래 ID 대응.

기존 참조 검사 21개, 국소 확장 5개, 문맥 건넘 7개도 통과했다. 생성된 JavaScript는 `node --check`를 통과했다.

로컬 HTTP 미리보기에서 미분 지도 확대, 첫 변분의 입력 누락 경고, edge e4의 전체 진술과 양 끝 상태, 핵심어를 끈 ID 전용 표시를 확인했다. 화면 사본은 `diff-status.png`다. 원본 file URL과 같은 생성 HTML이며, 소스의 증명 내용·status·confirmed는 변경하지 않았다.
