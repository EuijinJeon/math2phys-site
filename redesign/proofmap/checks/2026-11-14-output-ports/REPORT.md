# 출력 항목 참조와 c1 경로

2026-11-14. 사용자의 지적은 **D2의 출력에 없는 설명을 e4에 추가하면서 두 내용이 어긋났다는 것**이었다. 이전의 입력 선 누락 표시는 별도 문제이며 그 지적의 해결이 아니었다.

## 출력 항목 시범 적용

첫 변분의 조건부 평균·kernel 합성 등식, path 평균의 뜻과 성립 조건을 `diff.D2.outputs.kernel_form` 한 곳에 선언했다. 원문 trees.tex 142–154, kernel 정의 67–82 및 prefix 정의 20–23과 대조했다. 내부 `fv.CP`와 `cp`의 적분 합성·조건부 평균 대입이 그 출력을 만드는 연결이다.

- D2, fv.CP, fv.OUT, cp.IDENT, cp.END, fresh.FP_VAR는 `statement_ref`로 같은 선언을 읽는다. 이 참조는 결과의 표기이며 유도의 입력 전제로 추가한 것이 아니다.
- e4와 fp-first는 `output_ref`로 그 출력을 전달한다. source JSON에서 독립 statement 사본을 없앴다.
- “FP_BIND가 d=d_beta를 대입한다”는 설명은 e4의 `use_note`로 분리했다. 수학적 출력에 포함시키지 않는다.
- D4와 FP_BIND는 `input_ports.first_variation`에 필요한 출력과 검토 지문을 기록한다.
- 출력 선언에는 fv.CP 및 하위 cp의 의미 관련 자료를 반영한 증명 지문과, 그 출력 내용의 검토 지문을 기록한다. 배치만 바꾼 경우는 무효화하지 않는다.
- 출력·조건·내부 증명 변경, 없는 출력·수신 요구 불일치·중복 사본·검토 누락을 진단한다. 영향을 받는 후속 node도 재검토로 표시한다.

정상 상태 e4 패널은 “출력 참조 연결됨 · 검토 기록 일치”, 참조명 `diff/D2.kernel_form`, 별도의 사용 설명과 전체 진술을 보여 준다. HTML에는 참조한 전체 내용과 조건을 펼치므로 읽을 때 별도 파일을 열 필요가 없다.

이는 작성자의 내용 대조 기록이며 독립 감사나 사용자 confirmed가 아니다. 해시는 변경을 찾고, 수학적 함의는 사람이 검토한다. 기존의 다른 edge 전체에 적용한 것이 아니며, 자동으로 모든 논리적 불일치를 검출하는 기능도 아니다. XO→D2의 명시적 입력 선 누락은 그대로 별도 표시한다.

## c1 라벨의 원인과 수정

`fresh`에서 `FP_LOG → FP_PACK`의 직선 사이에 `FP_BIND`가 같은 row에 있었다. 이전 알고리즘은 연결선을 그대로 두고 라벨만 node를 피해 옮겼다. 따라서 c1의 라벨이 연결선·node의 관계와 어색하게 떨어져 보였다.

이제 연결선도 장애물 node 위·아래를 우회한다. c1의 실제 브라우저 경로는 `(129,275) → (129,253) → (929,253) → (929,275)`로, 가운데 FP_BIND 상자의 위를 지난다. 라벨은 이 실제 경로 위의 기준점에 놓고 떨어지면 보조선으로 이어 준다. 노드나 계수의 수학적 의미를 바꾼 것은 아니다.

## 검증

- 출력 참조 결함 주입 시험 12개: 정상 확장, 출력·조건·증명 변경, 후속 전파, 배치 변경의 무해성, 누락 출력·잘못된 요구·중복 사본·검토 누락·없는 입력 연결·잘못된 node 참조.
- 기존 보기 10개, 참조 검사 21개, 국소 확장 5개, 문맥 건넘 7개. **Python 시험 합계 55개 통과.**
- Node 경로 시험: c1의 장애물 우회, 우회선 위의 라벨 기준점, 장애물 없는 선의 직선 유지. 생성 JavaScript 문법 검사 통과.
- 브라우저에서 e4의 공통 출력 참조·사용 설명 분리와 c1의 실제 우회 경로를 확인했다. 화면 사본은 `output-contract.png`, `c1-route.png`다.
- JSON Schema도 선택적 필드를 문서화했다. 환경에 jsonschema 엔진이 없어 별도 엔진 적용 검사는 하지 않았다. 실제 기준 자료는 표준 라이브러리 검사에서 오류 0·경고 0이다.

원본 graph는 계속 `graphs/move4.json`이다. `edge-e4-export.json`은 생성·전달된 전체 내용을 확인하는 사본이며 직접 수정하는 자료가 아니다.
