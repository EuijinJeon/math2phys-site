# PoC 2 — vertex 단독 독립 검증

2026-11-14. 대상은 `fv.PM` 하나다. **사전 고정한 국소 통과 기준을 충족했다.** 다른 vertex나 전체 증명 지도의 정확성까지 검증한 결과는 아니다.

## 설계

실행 전에 `protocol.json`에 배정, 통과 기준, 한계를 기록하고 두 packet의 SHA-256을 고정했다. packet은 node의 유도, 해당 문맥과 바닥, 받는 edge, 보내는 edge만 담았다. 작성자가 채운 부분도 포함하되, 기존 작성자의 자체 review는 주지 않았다.

작성에 참여하지 않은 gpt-6-astra 신규 agent 두 개를 각각 `fork_turns=none`, reasoning effort high로 실행했다. 각 검토자는 자신의 packet 하나만 읽도록 지시받았고 실제 도구 사용 및 자기보고도 cat 1회로 일치했다. 원문·주변 graph·다른 packet을 읽지 않았다. 파일 권한 격리는 아닌 지시적 격리다.

| 조건 | 입력 | 독립 판정 | 사전 기준 평가 |
|---|---|---|---|
| R | PM 입력 전체 | closed. 유도 6줄 valid, 출력 o1/e4 모두 생산 | 통과 |
| S | 동일 vertex에서 e2만 삭제 | repairable_gap. kernel 정의 누락, 5행과 o1 식별 불가 | 통과 |

S 검토자는 단순한 “참조 ID 없음”에 그치지 않았다. 누락된 정의의 식을 제시했고, 기존 입력으로 정규화 가중 평균을 만들면 도함수 경계 e4는 여전히 생산된다고 구별했다. 즉 정의 누락의 영향이 모든 출력을 무효로 만드는 것은 아니라는 점까지 찾아냈다. 이 때문에 누락 탐지를 실질적인 성공으로 판정한다.

## 결과의 범위

- 원본 PM에서 새 결함은 발견되지 않았다. 그래프를 수정하거나 재응시시키지 않았다.
- PM의 author_filled인 균일 도함수 경계는 전체 입력을 받은 검토자가 적분·미분 교환의 충분한 근거로 확인했다.
- 삭제한 것은 예시로 제안되었던 e3이 아니라 **e2(kernel 정의)**다. e3이 수학적으로 필수인지에 대한 별도 최소성 시험을 한 것은 아니다.
- 각 조건 n=1이고, 검토자는 같은 모델의 별도 세션이다. 일반적인 오류 탐지율이나 서비스 간 재현성은 측정하지 않았다.
- 삭제 후에도 유도 안의 e2 참조는 남아 있다. 숨은 결함 탐지나 눈가림 시험은 아니다. 대신 누락의 수학적 내용과 실제로 영향을 받는 출력까지 설명해야 통과하도록 실행 전에 정했다.
- 원문과의 일치, 다른 vertex의 완결성, PM을 원자 계산으로 볼지 및 바닥의 적정성은 이번 시험 범위 밖이다.
- 사용자만 지정할 수 있는 confirmed 상태는 변경하지 않았다.

## 자료

- `protocol.json`: 실행 전 설계와 입력 해시.
- `packet-r.json`, `packet-s.json`: 동결 입력.
- `review-r.md`, `review-s.md`: 독립 응답의 판정·논증 기록. 수식 표기와 파일 경로를 정리한 전사이며 문자 단위 원본은 아니다.
