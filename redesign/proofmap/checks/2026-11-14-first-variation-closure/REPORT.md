# 첫 변분 연결의 완결과 재검토 순환

2026-11-14. **첫 변분 D2의 입력부터 내부 유도, 출력 e4, fresh path의 FP_BIND까지 국소 연결을 닫았다.** D2와 D4는 현재 자료와 생성 화면 모두 국소 완결이다. 미분 규칙 전체(diff)는 아직 미완결이다. 작성자의 원문 대조이며 새 독립 감사나 사용자 confirmed 승인은 아니다.

## 입력과 출력 경계

추가한 `diff-e9: XO → D2`는 유한 kernel 열과 지수, 매개변수에 무관한 유계 D_j, 양의 상·하한을 갖는 A_t의 근방, root 고정, Y 재귀와 삽입 후 kernel 정의 및 정규화, 재귀의 단조성, prefix와 조건부 path 평균 정의를 싣는다. 첫 변분 결론 자체를 입력으로 넣지 않았다. 공급 node XO가 상속하는 top.O1에도 path 평균과 고정 kernel의 뜻을 명시했다.

| 전달 내용 | 하위에서 받는 곳 | 쓰이는 단계 |
|---|---|---|
| Y_L=A, power mean 재귀 | fv.X1 | TM의 말단 미분, PM의 한 칸 미분 |
| tilted kernel 정의 | fv.X2 | PM에서 미분 결과를 K^A 평균으로 식별 |
| a≤Y_d≤b | fv.X3 | PM의 로그 정의와 미분·적분 교환의 지배상계 |
| E^A[·|prefix]의 kernel 합성 정의 | fv.X4 | CP/cp.IDENT에서 합성을 조건부 평균으로 식별 |

원문 대조: trees.tex 20–23, 67–82, 107–110, 142–154. TM의 로그 미분, PM의 m b^m c 지배상계와 확률 평균에 의한 경계 유지, CP의 유한 하향 귀납으로 선언한 모든 깊이의 kernel_form이 나온다. 그 지배상계는 기존 author_filled 표기를 유지했다.

D2는 `outputs.kernel_form`을 계속 한 번만 선언한다. fv.CP와 cp의 내부 유도 결과를 이 출력과 연결하고, fv.f4도 같은 출력 참조를 전달하도록 바꿨다. e4와 fresh.fp-first는 동일 항목을 읽으며 FP_BIND가 d=d_beta의 대입을 수행한다. 대입 수행 위치에 대한 사용 설명은 수학적 출력에서 분리한 상태를 유지했다.

## 변경 의존성의 보강

이전 지문은 fv/cp 내부만 추적하므로 바깥의 정의 입력 변화가 빠질 수 있었다. 이제 proof_snapshot은 각 하위 graph의 부모 vertex가 실제로 받는 edge와 그 공급 node의 상속 진술도 포함한다. XO의 공급 정의나 diff-e9가 바뀌어도 출력과 수신 대응이 재검토 상태가 된다.

검토 지문 자체는 수학적 명제가 아니므로 이 의존성 지문에서 제외했다. 같은 출력이 내부 출력 edge로 되돌아오는 경우에도 hash(hash(...)) 고정점을 만들지 않는다. 검토 기록을 저장한 뒤 다시 생성하는 것만으로 새 경고가 생기지 않는다는 시험을 추가했다. 배치 좌표 역시 계속 제외한다.

## 조건 변경 → 재검토 → 완결 복귀

`test_review_cycle.py`는 원본을 메모리에 복사한 뒤 조건에 **A_t≥2a인 부분영역에 제한한다**는 조건을 추가했다. 실제 저장된 출력 조건은 바꾸지 않았다. 이 추가 조건은 기존 A_t≥a의 부분영역을 택하므로, 원래의 로그 미분·지배상계·kernel 합성과 FP_BIND 대입은 그대로 유효하다. 이 수학적 이유를 검토한 뒤 시험 사본에서 출력 유도와 각 수신의 검토 지문을 각각 갱신했다.

| 단계 | D2, D4, FP_BIND, FP_PACK |
|---|---|
| 기준 자료 | 모두 국소 완결 |
| 추가 조건, 검토 기록 유지 | 모두 미완결·재검토 |
| 수신 기록만 갱신 | 모두 미완결 유지 |
| 유도 기록만 갱신 | 모두 미완결 유지 |
| 유도와 모든 수신 기록 갱신 | 모두 국소 완결로 복귀 |

지문을 바꾸면 수학적 검토가 자동으로 이루어진다는 뜻은 아니다. 시험에서는 위의 부분영역 논증을 직접 확인했고, 이후 기록 갱신이 올바르게 동작하는지를 점검했다. 원본이 이 시험 때문에 자동 승인되지는 않는다. 단계별 원인과 상태는 `review-cycle-results.json`에 남겼다.

## 검증과 남은 범위

- 새 순환 시험 4개: 양쪽 검토 필요, 바깥 입력 수정, 상속한 정의 수정, 지문 자기참조 방지.
- 기존 출력 참조 12개, 보기 11개, 명시 참조 21개, fresh path 수치 5개, 문맥 건넘 7개. **Python 시험 총 60개 통과.**
- 기존 보기 시험 하나는 입력 삭제가 이제 내부 CP의 검토까지 무효화함에 맞춰 기대 상태를 갱신했다. 삭제를 허용하거나 검사 규칙을 완화한 것은 아니다.
- Node 연결선 경로 시험 통과. 전체 check.py는 오류 0·경고 0. 생성기에서 diff는 국소 완결 2, 미완결 2, 미평가 1, 입력 누락 0이다.
- 브라우저에서 e4의 양 끝 D2·D4가 모두 국소 완결, 출력 검토 기록 일치, 새로운 정의 edge e9 존재를 확인했다. 화면 저장이 한 차례 지연되어 재연결 후 다시 확인하고 `closed-connection.png`를 저장했다.
