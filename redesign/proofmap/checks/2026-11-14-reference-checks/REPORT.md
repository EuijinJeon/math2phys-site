# PoC 3 — 명시 기호·참조 검사

2026-11-14. **국소 PoC 기준을 충족했다.** `check.py`가 기호의 정의 위치와 받는 edge의 사용 여부를 보고한다. 현재 완결된 원자 vertex 5개(`TM`, `PM`, `BASE`, `JOIN`, `IDENT`)에 적용했으며 기준 graph는 오류 0·경고 0이다. 상위 미완결 graph의 모든 수식에 적용한 것은 아니다.

## 변경

- node의 `reference_check: true`로 명시 검사에 참여한다. 이전 형식은 계속 읽고 명시 참조 미검사임을 보고한다.
- edge·문맥·유도 줄의 `defines`는 기호의 정의 위치를 색인한다. 줄별 `uses_symbols`는 그 줄에 필요한 기호를 열거한다.
- 줄별 `uses`는 받는 edge, 해당 node를 포함하는 문맥, 앞선 줄, 선언된 바닥을 정확한 id/번호로 참조한다. 기존 `by` 설명은 유지한다.
- 실제로 쓰이지 않은 입력은 `EDGE_UNUSED` 경고, 없는 정의·잘못된 범위·미래 줄은 오류다. 출력의 `lines`도 실제 유도 줄에 닿아야 한다.
- 선택적 필드를 JSON Schema 및 `SPEC.md`에 문서화했다. 내용의 자동 의미 판정을 추가하지 않았으므로 format `proofmap/0.1`은 유지한다.

## 검증

`python3 redesign/proofmap/tools/test_check.py`: **21 tests, OK**. 저장된 graph를 메모리에서 복사해 다음 결함을 넣었다.

- `PM`의 e2 삭제: `REF_SCOPE` 및 `SYMBOL_UNDEFINED` 오류. 실제 CLI 종료 코드 1, 기호 `K_A`를 지목.
- edge는 그대로 두고 정의 선언만 삭제: 미정의 기호 오류.
- 같은 graph의 다른 node로 가는 edge, 없는 edge id, 다른 graph의 문맥, 해당 node를 포함하지 않는 문맥: 범위 오류.
- 자기 줄·미래 줄·없는 바닥 참조: 범위 오류.
- 정의를 뒤로 옮기거나 국소 정의를 삭제: 선행 정의 부족 오류. 정상 `h` 정의는 `line:1`로 보고.
- `by`에는 e3을 남기고 모든 `uses`에서만 삭제: 사용하지 않은 입력 경고. 산문의 부분 문자열로 사용 판정을 우회하지 못함.
- 잘못된 필드 타입, 기호 목록 누락, 없는 출력 줄, bool 줄 번호, 실제로 보내지 않는 출력: 오류.
- 명시 검사를 쓰지 않는 이전 node: 미검사 표시. 중복 문맥 id: 오류.

기준 graph의 상세 출력은 `check-results.json`에 저장했다. 보기 생성도 통과했다. 이전 PoC 2의 동결 packet SHA-256은 변하지 않았다. 수학적 유도와 사용자 전용 `confirmed`는 바꾸지 않았다.

JSON Schema 파일과 실제 graph는 JSON으로 읽어 확인했다. 이 환경에는 `jsonschema` 패키지가 없어 JSON Schema 엔진으로 적용하는 검사는 생략했다. 검사기와 회귀 시험은 표준 라이브러리만으로 실행된다.

## 해석의 한계

이것은 **사람이 작성한 선언과 참조의 일관성 검사**다. 기호가 수식에 있지만 `uses_symbols`에서 빠진 경우, `defines`에 허위 정의를 적은 경우, 같은 기호를 서로 다른 의미로 쓴 경우를 자동 탐지하지 않는다. 또한 참조한 내용이 해당 수식을 정말 증명하는지는 독립 수학 검토가 맡는다. 검사 통과가 자동 증명 인증은 아니다.

다음 권장 PoC는 4번: 고정한 L의 P7에서 L→∞를 사용하는 수 5로 넘어가는 edge 하나에 균일성과 극한 순서를 명시하는 것이다. 이번 작업은 검사 보강으로 종료한다.
