# 재설계 로드맵과 진행 기록

상태 표기: ⬜ 대기 · 🔄 진행 중 · ✅ 완료 · ⚠ 문제 있음 · 👤 사용자 확인 필요

### 1단계. 시범 (현재)

목표: 물리판이 실제로 닫히는지와 카드 형식이 증명을 담을 수 있는지를 가장 싸게 시험한다.

| 작업 | 담당 | 상태 | 산출물 |
|---|---|---|---|
| 1A. 추출·검사·생성 도구 | 하위 에이전트 (sonnet) | ✅ | `tools/`, `build/` |
| 1B. 논문 전체 L0, L1, 규칙 표 | 하위 에이전트 (opus) | ✅ 초안 | `layers/` |
| 1C. §7 노드 카드 전부 | 하위 에이전트 (opus) | ✅ 초안 | `cards/decor.*` |
| 1D. 통합: 검사 통과, 카드와 규칙 표 맞춤 | 이 세션 | ✅ | `build/check-report.md` |
| 1E. 독립 검토: 규칙 표와 §7 카드의 건전성 | 하위 에이전트 둘 (작성자와 다른 모델) | 🔄 | `build/review-1-rules.md`, `build/review-1-cards.md` |
| 1F. 시범 판정 | 👤 | ⬜ | 아래 "판정" |

**시범 판정 기준**
1. 규칙 표가 열 줄 안팎으로 닫히는가. L1의 각 수가 그 규칙만으로 이어지는가.
2. §7의 모든 증명 줄이 잎 카드에 들어가는가(포함 검사).
3. 독립 검토에서 건전성 오류가 구조를 흔들 만큼 나오는가.

## 진행 기록

### 2026-11-11

- 원문 확인: 섹션 파일 11개, 약 2,800줄, 정리류 환경 26개, `\label` 128개, 참조 118개.
- `source/`에 원문 복사, 출처 표기(`source/NOTICE.md`).
- `SCHEMA.md` 작성.
- 1A, 1B, 1C를 하위 에이전트 셋에 병렬로 맡김.
- 1B 초안 도착: 규칙 12개(P1–P12), L1은 일곱 수, L0 한 문단. 모든 노드 ID를 원문 `\label`과 대조함(작성 에이전트 보고).
  - 작성 에이전트가 꼽은 확신 낮은 대응: P7(GG 항등식의 꼴), P8·P9(여기서의 "상태"는 보조 계층이지 물리적 pure state가 아님), P11(독립성의 근거가 국소 tree 구조가 아님), P4(극한 존재를 가정하지 않음), P5.
  - 기존 역할 표에 대한 지적: multioverlap $R_S$, reservoir와 증분 $\Delta_N$, score, $\mathcal A_{L,\eta}$ 등 핵심 대상이 빠져 있음. R11·R19·R22는 하한 증명에서 보조 계층을 물리적 상태로 읽게 만들어 논문의 "ultrametricity를 가정하지 않는다"와 어긋날 수 있음. 👤 확인 필요.
- 1A 완료: `tools/extract.py`(노드 160개: 정리류 30, 식 100, 섹션·소절 28 등, 참조 간선 166개, 문장 890개), `tools/check.py`(검사 7종 + 머리말 형식), `tools/build.py`(정적 HTML: 증명 지도, 카드별 펼침 화면).
  - 원문에 `definition` 환경은 없음. 정의는 모두 본문 서술이라 카드 작성 시 `x:` ID로 직접 묶어야 함.
  - 생성 화면의 Mermaid·MathJax 렌더링은 브라우저에서 아직 확인하지 않음.
  - 카드 종류에 `section` 추가(섹션 최상위 카드용).
  - 현재 실제 트리에서 연결·사전·단면 검사는 `rules.md`, `L1.md`에 대해 통과. 카드 검사는 1C 도착 후.
- 1C 초안 도착: §7 카드 54개. 정리류 6, 준비물(약속·정의·작은 보조정리) 14, 증명 단계 33, 섹션 카드 1. 잎 43개.
  - §7이 밖에서 받는 것: `pert:selection`, `pert:tree-identity`, `tree:extension-expansion`, `tree:reference-total`, `tree:charging`, `tree:multioverlap`, tree 표본추출 규칙.
  - §8이 §7에서 쓰는 것은 `decor:overlap-concentration` 하나(와 깊이 평균의 정의).
  - 작성 에이전트가 ❓로 남긴 곳 2군데, 원문에 없는 것을 명시적으로 보탠 곳 4군데. 독립 검토 대상.
  - 기존 노트에 대한 지적: 07-1의 "같은 깊이 상태의 두 replica의 overlap은 $q_d$로 고정"은 원문이 증명하는 것(각 $N$에서 평균 주위 집중)보다 강함.
- 1D 통합: 검사 8종 전부 통과. 단, 통과시키려고 검사 규칙 두 가지를 바꿨다(카드 내용은 손대지 않음).
  1. 포함: 정리의 진술 줄은 잎이 아닌 카드(그 정리 카드 자신)가 덮어도 된다. 원래 규칙은 진술까지 잎이 덮으라고 해서 설계와 어긋났다.
  2. 의존: 본문에서 원문상 뒤에 나오는 대상을 가리키는 참조(§7 서두의 "§8에서 쓴다")는 의존이 아니라 예고로 보고 제외한다.
- 화면 확인: 헤드리스 브라우저에서 카드 54쪽 전부 수식 오류 0건(수식 3,470개). 증명 지도, L0, L1, 규칙 표도 정상. 지도가 잘리던 문제 수정.
- 1E 시작: 규칙 표·L0·L1 검토와 §7 카드 검토를 별도 에이전트 둘에 맡김.
