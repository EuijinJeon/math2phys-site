# 규칙 표 — The Mézard–Parisi formula for diluted spin glasses

**바닥**: 대학원 통계역학(분배함수, pressure $=-\beta f$, 열역학 극한), diluted spin glass의 cavity method(cavity field, Bethe free entropy의 site 항과 edge 항), replica 방법과 Parisi RSB(Parisi parameter $m$, 물리적 pure state, overlap)의 기초. P7 항등식과 물리 선행 연구의 관계는 [[g:tree-identity]]의 물리 대응 칸에 있다.

기호와 용어는 [용어집](glossary.md)을 따른다. 이 표에서 자주 쓰는 것을 다시 적으면:
- $R_S=\frac1N\sum_i\prod_{a\in S}\sigma_i^a$ 는 replica 집합 $S$ 의 multioverlap([[g:multioverlap]]).
- $L\ge2$ 는 보조 계층의 깊이($r=L-1$단 RSB). 하한 내내 $m_d=d/L$([[g:grid]])이고 $\mathbf m^{(L)}=(1/L,\ldots,(L-1)/L)$. [[g:order-parameter]]의 $\mathcal M_{r+1}$ 은 여기서 $\mathcal M_L$ 이다([[g:rsb-steps]]).
- [[g:reservoir|reservoir]]는 크기 $N$ 과 $N+1$ 의 계를 비교하는 공통 $N$-spin 계다(`cavity:increment`). $P_N^{L,\mathbf u}$ 는 섭동 매개변수 $\mathbf u$ 로 섭동된 leaf 분배함수에 power-mean 재귀를 적용한 뒤의 [[g:root-logarithm|root logarithm]] 기대값이고, $\Delta_N=P_{N+1}^{L,\mathbf u}-P_N^{L,\mathbf u}$ 는 그 [[g:increment|cavity 증분]]이다.
- $\underline F$ 는 bounded 모형의 모든 크기에 대한 $\liminf_NF_N$ 이고, $\varepsilon>0$ 은 P5의 선택 여유다([[g:lower-pressure]]). P5가 고르는 크기와 매개변수의 수열을 [[g:selected-sequence|선택된 수열]]이라 부른다.
- 섭동 type $\nu$ 마다 [[g:score|perturbation score]] $D_\nu$ 는 그 섭동의 $u_\nu$ 미분(`pert:score`), score 오차 $e_{\nu,N}$ 은 그 정규화된 평균 절대 편차다(`pert:error`). score가 "[[g:concentration|집중]]한다"는 것은 $e_{\nu,N}\to0$ 을 뜻한다.
- [[g:prescribed-tree|prescribed tree]]는 깊이 $L$ 까지의 유한 [[g:replica|replica]] tree이고, [[g:anchor|anchor]]는 그 tree에서 고른 한 replica다(`pert:tree-identity`). "상태"는 보조 계층의 깊이 $d$ prefix만 뜻한다([[g:state]]).
- $\eta>0$ 은 깊이 regularity 매개변수(정규화된 깊이가 $(\eta,1-\eta)$ 안에 있고 서로 $\eta$ 보다 더 떨어짐)이고([[g:eta-regular]]), $\mathcal A_{L,\eta}$ 는 $\eta$-regular한 내부 branching 깊이들에 대한 평균이다([[g:depth-average]]).

## 확신이 낮은 대응

- **P6 (power mean, tree 계수, tree 법칙의 물리 읽기)**: 예전 역할 표는 power mean, $\gamma_\beta$, $Q_k$ 를 각각 Ruelle cascade 평균, Parisi block counting, cascade에서 뽑은 replica tree 법칙으로 읽었다. 용어집은 이 읽기를 [[g:power-mean]], [[g:tree-coefficient]], [[g:tree-law]]의 물리 대응 칸에 intuition으로만 둔다. 논문은 이 항등식들을 임의의 유한 kernel 열에 대해 직접 세우고 cascade와의 동일시를 증명하지도 쓰지도 않는다. 그래서 이 이름들은 P6의 규칙 문장에서 빼고 차이 칸에 intuition으로 적었다. 물리 그림으로는 맞는 읽기일 가능성이 크지만 여기서 확인하지 않았다.
- **P7 (prescribed-tree 항등식의 이름)**: 논문의 항등식은 extension history에 대한 부호 있는 합이고, 물리에서 익숙한 이름의 항등식과 같은 꼴이 아니다. 그래서 이름 대신 역할, 곧 "이 항등식과 tree 표본 규칙만으로 §7의 집중(수 5)이 모형과 무관하게 나오고, 수 6은 거기에 factorization·positivity를 쓰지 않는 입력(P4, P5(i), P6, P10, 균일 site 표본)만 더한다"는 사실을 P7 차이 칸과 [[g:tree-identity]] 역할 칸에 근거 행과 함께 적었다. 논문이 드는 antecedent(`perturbations.tex` 17–21행)는 같은 항목의 물리 대응 칸에 intuition으로만 남겼고, 두 꼴이 서로 유도되는지는 확인하지 않았다.
- **P8, P9 (상태, 공통 조상 깊이)**: 이 규칙들의 "상태"와 "깊이"는 보조 계층(섭동 mark를 power mean으로 tilt한 것)의 것이다([[g:state]], [[g:depth]]). 논문은 서론에서 물리적 Gibbs 측도의 계층 조직을 가정하지 않는다고 명시한다(`introduction.tex` 75–77). 예전 역할 표의 물리 해석("깊이 $d$ = 물리적 pure state 계층의 단계", "tilt = 물리적 pure state 가중치")을 그대로 얹으면 논문이 하지 않은 주장을 하는 셈이 된다. 그래서 "상태"는 보조 계층의 prefix만 가리키고, 물리 쪽 대상은 [[g:physical-pure-state]]로 따로 둔다.
- **P8의 주어(조건부 공분산)**: $v_N(S,d)$ 는 $N^{-2}\sum_{i,j}\operatorname{Cov}(A_{S,i},A_{S,j}\mid\mathscr F_d)^2$ 이다. replica 곱 벡터의 조건부 공분산이므로 $S$ 가 여러 잎을 가지면 단일 replica의 spin 상관이 아니다. 예전 판은 예전 역할 표를 따라 규칙 문장의 주어를 물리 이름으로 썼지만, 원문은 "squared conditional covariance of the spin-product vector"(`decorrelation.tex` 78–79)라고만 하므로 주어를 조건부 공분산([[g:conditional-covariance]])으로 바꿨다. 물리 이름과의 대응은 잎이 하나인 경우에만 성립하며, 그 항목의 물리 대응 칸에 그 단서와 함께 있다.
- **P11 (독립의 원인)**: 물리의 cavity 논증은 이웃 cavity field의 독립을 "그래프가 국소적으로 tree이고 한 물리적 pure state 안에서 상관이 감쇠한다"로 정당화한다. 논문의 증명은 그래프의 국소 tree 구조를 쓰지 않고, 무작위 site 표지와 multioverlap 집중(P9)으로 독립을 얻는다. 논문이 "국소 구조를 쓰지 않는다"고 문장으로 말하지는 않으며, 이것은 증명에 쓰이지 않는다는 데서 읽은 것이다. 또 P9의 증명은 P8(보조 계층 prefix 안의 조건부 공분산 소멸)을 재료로 쓰므로 "상관 감쇠와 무관하다"고 읽으면 안 된다. 거꾸로 P8 혼자서 독립성을 주지도 않는다(P8 차이 칸). 쓰이지 않는 것은 그래프 거리에 따른 상관 감쇠다. 규칙 문장은 맞지만 물리학자가 떠올리는 이유는 틀릴 수 있다. 이 차이를 "차이" 칸에 적었다.
- **P5 (선택된 수열)**: 예전 판은 이 행의 대상을 "generic 상태"라고 불렀지만, 그것은 보조 계층의 prefix가 아니라 고른 크기와 섭동 매개변수의 수열이므로 [[g:selected-sequence|선택된 수열]]로 바꿨다. P5의 근거는 섭동 도함수의 집중(`pert:concentration`)이고, 증분을 낮게 유지하는 조건(i)과 집중(ii), 모멘트 수렴(iii)을 동시에 고르는 것은 물리 그림에 없는 수학적 선택이다. 그래도 진술이 그대로 쓰기 좋아서 물리 규칙과 같은 층에 두고, 차이 칸에 수학적 선택 lemma임을 적었다.
- **P4와 극한의 존재**: 물리판이 "$\lim F_N=\lim\Delta_N$"을 규칙으로 쓰면 틀린다(논문은 그것을 증명하지 않는다). P4는 증분 항등식 자체로만 써야 하고, L1의 하한 유도는 $\liminf$ 형태로만 닫힌다.
- **P1의 부호 조건 해석**: "$\mathbb E[(-b)^n]\ge0$ = frustration이 대칭이거나 반강자성 쪽"은 예전 역할 표의 제안 해석이다([[g:positivity]]). 대칭 $J$ 와 soft SAT($-1<b\le0$)에서는 맞지만 일반적인 동치 조건은 아니다. 이 행은 수식으로 읽어야 한다.
- **P1의 짝수 $p$ 역할**: 짝수 $p$ 가 직접 쓰이는 곳은 상한의 볼록성 단계뿐이지만, 논문은 $p$ 를 처음부터 짝수로 고정하고 하한이 홀수 $p$ 에서도 성립한다고 말하지 않는다. 그래서 P1 차이 칸은 "짝수 $p$ 는 상한에만 쓰인다"고 쓰지 않았다.
