L1 — 증명 한 쪽

바닥: 대학원 통계역학, diluted spin glass의 cavity method, replica와 Parisi RSB의 기초(overlap, Parisi parameter). 규칙 P1–P12와 P6′ 은 rules.md, 용어와 기호는 용어집.

기호: $\alpha$ 는 spin당 평균 factor 수, $p$ 는 짝수 체수용어. $F_N$ 은 pressure용어. $\zeta$, $\mathbf m$ 은 $r$단 RSB order parameter와 Parisi parameter(order parameter $\zeta$ 와 $\mathcal M_{r+1}$, Parisi parameter $\mathbf m$). $\mathcal B_r(\zeta,\mathbf m)=\log2+\mathbb E\log T_0V_{\rm s}-\alpha(p-1)\mathbb E\log T_0V_{\rm e}$ 는 $r$단 RSB Bethe free entropy(시행 functional $\mathcal B_r$; $V_{\rm s}$ site 항 $V_{\rm s}$ 와 $U_\theta$, $V_{\rm e}$ edge 항 $V_{\rm e}$ 와 $C_\theta$, $T_0$ power mean $T_d$). $\Phi_r=\inf_{\zeta,\mathbf m}\mathcal B_r$용어. reservoir는 크기 $N$ 과 $N+1$ 을 비교하는 공통 $N$-spin 계, $\Delta_N$ 은 섭동된 계의 $N\to N+1$ 증분용어, $Y_{0,\rm s}$, $Y_{0,\rm b}$ 는 site·bond 삽입의 계층 free entropy 변화용어. $L$ 은 보조 계층의 깊이이고(수 6의 encoding이 이것을 $r=L-1$단 시행 법칙으로 옮긴다, RSB 단계 수 $r$ 와 계층 깊이 $L=r+1$), 하한에서는 $m_d=d/L$, $\mathbf m^{(L)}=(1/L,\ldots,(L-1)/L)$용어. 상태는 보조 계층의 깊이 $d$ prefix만 뜻한다. $R_S$ 는 replica 집합 $S$ 의 multioverlap $\frac1N\sum_i\prod_{a\in S}\sigma_i^a$용어. prescribed tree는 깊이 $L$ 의 유한 replica tree, mark는 깊이별 무작위 부호, $Q_k$ 는 $\log$ 전개의 tree 법칙용어. $\underline F=\liminf_NF_N$(bounded 모형, 모든 크기; $\underline F$ 와 여유 $\varepsilon$). 증명할 식은 $\lim_N F_N=\inf_{r\ge0}\Phi_r$ 이다.

  1. 상한: interpolation
    • 무엇을 하는가: 실제 $p$체 factor를 $p$개의 cavity factor로 연속적으로 바꾼다(interpolation). P1의 가설을 모두 써서 나머지항은 0 이하다($x^p$ 의 볼록성, $\mathbb E[(-b)^n]\ge0$, factorization의 독립 구조). 모든 $N$ 과 모든 시행값에서 $F_N\le\mathcal B_r$ 이 나오고, 이 부등식이 마지막 수 7로 간다. $\log a$ 의 적분 가능성은 가정하지 않는다: 상수 $c=\theta(1,\ldots,1)$ 을 빼면 $a$ 가 사라지고(세 삽입에서 상쇄), $\lambda<1$ 로 정규화한 급수에서 $\lambda\uparrow1$ 로 증분을 회복한다(upper:regularization).
    • 쓰는 규칙: P1, P2
    • 근거 노드: upper:bound, upper:derivative, upper:remainder, upper:regularization
  2. cavity reservoir와 증분 (이하 수 6까지 하한, bounded이고 순열 불변인 상호작용)
    • 무엇을 하는가: 평균 $N^{3/4}$ 개의 단일 site 섭동(값 $[1/2,3/2]$)을 더하고 power-mean 재귀를 적용한 root logarithm $P_N^{L,\mathbf u}$ 는 $P_N^{L,\mathbf u}/N-F_N\to0$ 을 만족한다. $\Delta_N=P_{N+1}^{L,\mathbf u}-P_N^{L,\mathbf u}$ 을 reservoir에 site 하나와 bond들을 넣는 차 $\log2+\mathbb E\log Y_{0,\rm s}-\mathbb E\log Y_{0,\rm b}+o(1)$ 로 쓴다. 이 식이 수 3과 6의 대상이다. $Y_{0,\rm s}$, $Y_{0,\rm b}$ 는 site·bond 삽입 $A_{\rm s}$, $A_{\rm b}$ 에 reservoir의 tilted kernel로 power-mean 재귀를 적용한 root 값이다(insertion $A$ 와 $\log Y_0$, cavity.tex 56–58). $L\ge2$ 에서는 일반적으로 보통의 분배함수 비 $Z'/Z$ 가 아니다($L=1$ 이면 같다).
    • 쓰는 규칙: P3, P4
    • 근거 노드: cavity:negligible, cavity:increment
  3. 선택된 수열 고르기
    • 무엇을 하는가: 여유 $\varepsilon>0$ 과 $L$ 을 고정할 때마다 크기 수열 $N_j$ 와 결정적 섭동 매개변수를 골라 $\Delta_{N_j}\le\underline F+2\varepsilon$ 이면서 reservoir의 모든 perturbation score(섭동 type별 $u$ 미분)가 집중하고(score 오차 $e_{\nu,N}\to0$) 유한 tree 모멘트가 수렴하게 한다. 이 선택된 수열(매 $L$, $\varepsilon$ 마다 다름)을 수 4–6이 공유한다. 물리 가정이 아니라 수학적 선택 lemma다.
    • 쓰는 규칙: P5
    • 근거 노드: pert:concentration, pert:selection
  4. branching pattern별 항등식
    • 무엇을 하는가: 새 섭동 하나의 효과를 replica tree 전개(extension history)로 풀고, score 집중을 넣어 prescribed-tree 항등식을 얻는다. mark가 anchor와 새 replica들로 이루어진 집합 안의 쌍별 split 깊이(새 replica끼리 포함)를 지정한다. 수 5가 모형에서 받는 입력은 이 항등식과 tree 표본 규칙뿐이고(decorrelation.tex 8–9), 수 5는 여기에 extension 계수의 합 $\kappa$ 와 계수 한계(P6′)라는 유한 tree 조합과 모형과 무관한 확률 부등식만 더한다. 수 5는 상호작용의 꼴(factorization 등)을 쓰지 않고, 수 6이 더하는 입력(증분 식, 선택된 수열, encoding, 균일 site 표본, log 전개)도 factorization과 positivity를 쓰지 않는다(cavity.tex 13–14).
    • 쓰는 규칙: P6, P6′, P7
    • 근거 노드: tree:extension-expansion, pert:palm, pert:analytic, pert:tree-identity
  5. 모든 multioverlap의 집중
    • 무엇을 하는가: 수 4의 항등식에 잎 개수 귀납을 걸되, target tree의 내부 branching 깊이를 한 칸씩 늦춘다(깊이 미루기): 늦춘 깊이마다 첫 fresh split이 정규화 계수와 같은 작은 인자 $\delta=1/L$ 을 낸다. 정규화 계수 $J=\kappa(S^+)^2$ 는 $\delta^{2b}$ 만큼 작지만($b$ 는 $S$ 의 branching vertex 수), 절댓값 계수 합의 상대 한계(P6′ 의 계수 한계, tree:charging)가 $J$ 로 나눈 뒤의 사영 오차를 $L$ 에 균일하게 제어한다(항등식 자체의 오차는 $J$ 로 나누면 $L$ 에 의존하는 상수가 붙고, 고정 $L$ 에서 $N\to\infty$ 로 먼저 사라진다; x:overview-step3). 이렇게 상태 안 조건부 decorrelation($\mathcal A_{L,\eta}v_N(S,d)\to0$, 조건부 평균 $\mu_{d,S}$ 와 조건부 공분산 제곱 $v_N(S,d)$)을 얻고, 이어서 marker anchor를 쓴 두 번째 항등식으로 $S$ 의 첫 split 깊이 $e$ 보다 한 칸 앞 prefix의 조건부 평균 $M=\mathbb E[R_S\mid\mathscr F_{e-1}]$ 의 분산을 각 고정 $L,S,e$ 에서 0으로 보낸다($\operatorname{Var}(M)\to0$). 그 prefix 아래의 남은 요동은 조건부 decorrelation과 깊이 연속성으로 깊이 평균에서만 제어되므로, $R_S$ 가 평균 $\mathbb ER_S$ 주위로 집중한다는 결론은 고정 깊이가 아니라 깊이 평균으로 나온다(singleton만 고정 $L$). $\eta>0$ 을 깊이 regularity 매개변수용어, $\mathcal A_{L,\eta}$ 를 $\eta$-regular한 내부 branching 깊이에 대한 평균용어이라 하면, 결과는 $\lim_L\limsup_N\mathcal A_{L,\eta}\operatorname{Var}(R_S)=0$ 이고($N$ 은 수 3의 수열, multioverlap 집중), 수 6이 이것을 쓴다. 이 수가 쓰는 것은 수 4의 항등식, tree 표본 규칙, 유한 tree 조합, 모형과 무관한 확률 부등식뿐이다.
    • 쓰는 규칙: P6′, P7, P8, P9
    • 근거 노드: decor:conditional-concentration, decor:overlap-concentration, tree:charging
  6. 독립 cavity message로 바꾸기
    • 무엇을 하는가: 무작위 site 하나의 계층 cavity field 분포로 시행 order parameter $\zeta_{L,N}$ 을 만든다용어. 수 5와 균일 site 표본을 써서 이웃 site들의 spin pattern을 그 독립 사본으로 바꾸면용어 $\lim_L\limsup_N\lvert\Delta_N-\mathcal B_{L-1}(\zeta_{L,N},\mathbf m^{(L)})\rvert=0$ 이다. 수 5의 깊이 평균은 $Q_k$ 평균으로 충분하고, $\eta$ 는 $L\to\infty$ 뒤에 0으로 보낸다용어. 수 2, 3과 합쳐 고정한 $\varepsilon$, $L$ 과 수열 위의 $N$ 에서 $$\inf_r\Phi_r\le\mathcal B_{L-1}(\zeta_{L,N},\mathbf m^{(L)})\le\Delta_N+\lvert\Delta_N-\mathcal B_{L-1}\rvert\le\underline F+2\varepsilon+\lvert\Delta_N-\mathcal B_{L-1}\rvert,$$ 이고 $\limsup_N$(그 $L$ 의 수열), $L\to\infty$, $\varepsilon\downarrow0$ 순으로 보내 $\underline F\ge\inf_r\Phi_r$ 을 얻는다.
    • 쓰는 규칙: P4, P5, P6, P9, P10, P11
    • 근거 노드: comp:encoding, comp:patterns, comp:insertion-comparison, comp:bounded-lower
  7. 일반 상호작용으로 넓히고 맞붙이기
    • 무엇을 하는가: 상수 $c=\theta(1,\ldots,1)$ 을 빼 $a$ 를 없앤다. $f_\ell$ 의 i.i.d.와 $b$ 의 독립(P1) 때문에 $\widehat\theta=\theta-c$ 의 법칙은 입력 순열에 대해 불변이다(원래 $\theta$ 는 아닐 수 있다). $\widehat\theta$ 와 $h$ 를 $[-K,K]$ 로 truncate하면 순열 불변성이 남아 수 6이 적용되고, Lipschitz 안정성으로 $\liminf_N\widehat F_N\ge\inf_r\widehat\Phi_r-2\alpha pD_K-2d_K$($D_K,d_K\to0$ 은 truncation의 $L^1$ 오차)이다. $K\to\infty$ 로 보내고 상수 이동을 되돌리면 $\liminf F_N\ge\inf_r\Phi_r$. 원래 법칙에 수 1을 적용한 $\limsup F_N\le\inf_r\Phi_r$ 와 맞붙여 극한의 존재와 공식을 얻는다.
    • 쓰는 규칙: P1, P2, P12
    • 근거 노드: reduction:stability, main:theorem

수학이 물리보다 더 해야 했던 일. 물리 유도는 수 4–6을 "물리적 pure state들이 계층을 이루고, 한 물리적 pure state 안에서 이웃 cavity field는 독립"이라는 가정 하나로 끝낸다. 논문은 이 계층을 가정하지 않는다. 대신 섭동 mark로 보조 계층을 직접 만들고($m_d=d/L$), 그 위의 prescribed-tree 항등식과 tree 표본 규칙만으로 모든 multioverlap의 집중을 증명한다. 이 집중은 고정 깊이가 아니라 깊이 평균으로, $N\to\infty$ 다음 $L\to\infty$ 의 순서로 증명된다. 부호 있는 tree 계수의 상쇄(미루기 전 $-\delta$ 대 $2+\delta$)를 깊이 미루기(수 5)로 제어하는 것이 핵심 기술이다. $\lim F_N=\lim\Delta_N$ 도 가정하지 않고, 수 3의 $\liminf$ 선택과 상한이 맞아서 극한이 나온다.
