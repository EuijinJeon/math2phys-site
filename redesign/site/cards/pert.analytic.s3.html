수학 진술

충분히 큰 모든 고정 $j$ 에 대해, 해당 type과 pert:palm이 $$\limsup_{N\to\infty}|H_N(j^{-1},0)|\le C\limsup_{N\to\infty}|u_{\nu,N}|\le2Cj^{-j}$$ 를 준다. 여기서 score 오차는 $j$ 고정에서 0으로 가고, pert:palm에 의해 모든 $j$ 에 같은 함수 $H_N$ 이 쓰인다. 따라서 $|H(j^{-1})|\le2Cj^{-j}$ 이다. $H$ 의 첫 0 아닌 Taylor 계수가 차수 $q$ 였다면 충분히 큰 모든 $j$ 에서 $|H(j^{-1})|\ge cj^{-q}$ 가 되어 모순이다. 따라서 $H$ 는 0 근처에서 항등적으로 0이고, 이것이 계수마다 주장을 증명한다.

본문

풀이(작성자). type $\nu=(\text{specification},j)$ 에서 $|H_N(1/j,0)|\le|H_N(1/j,u_{\nu,N})|+|u_{\nu,N}|\sup|\partial_uH_N|\le\|f\|_\infty e_{\nu,N}+C|u_{\nu,N}|$(pert:palm, pert:analytic.s1). $e_{\nu,N}\to0$ 은 pert:selection (ii)이고 $u_{\nu,N}\in I_\nu=[j^{-j},2j^{-j}]$ 는 선택된 벡터의 성분이다(pert:parameters). "충분히 큰 $j$"는 $1/j$ 가 s1, s2의 원판 안에 들어가기 위해서다. 상수 $C$ 가 $j$ 에 무관한 것(s1)이 결정적이다: 그래서 $j^{-j}$ 가 $j^{-q}$ 를 이긴다. "$H$ 가 0 근처에서 0"이면 모든 계수가 0이고, s2의 계수 수렴으로 $H_N(t,0)$ 의 각 계수가 0으로 간다.

원문 (perturbations.tex:411-425)

perturbations.tex:411-425

411For every sufficiently large fixed $j$, the corresponding type and
412Lemma~\ref{pert:palm} give
413\[
414 \limsup_{N\to\infty}|H_N(j^{-1},0)|
415 \leq C\limsup_{N\to\infty}|u_{\nu,N}|
416 \leq2Cj^{-j}.
417\]
418Here the score error tends to zero with $j$ fixed, and the same
419function $H_N$ is used for every $j$, by Lemma~\ref{pert:palm}.
420Hence $|H(j^{-1})|\leq2Cj^{-j}$.  If the first nonzero Taylor
421coefficient of $H$ had degree $q$, then
422$|H(j^{-1})|\geq c j^{-q}$ for all sufficiently large $j$, a
423contradiction.  Thus $H$ vanishes identically near zero, proving the
424claim coefficient by coefficient.
425\end{proof}
