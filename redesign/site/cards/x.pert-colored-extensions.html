수학 진술

$S_0=\sigma_i$ 일 때 anchor를 spin anchor, $S_0=1$ 일 때 marker anchor라 부른다. 추가 color는 $1,\ldots,k$ 로 순서가 있고 anchor는 color $0$ 이다. 추가 color들은 tree:extension-expansion의 canceled-anchor 확장 규칙에 따라, anchor와 같지 않은 서로 다른 replica 위치를 차지한다. 제약 $\mathcal C$ 는 추가 color들과 anchor만 관여하는 쌍별 split 깊이의 임의의 일관된 모임을 처방한다. 다른 old replica가 관여하는 추가 제한은 두지 않는다. $\mathfrak E(\mathcal T,a_*,\mathcal C)$ 를 허용된 extension history의 집합, $c_E$ 를 그 lemma의 계수라 하자. history $E$ 에 대해 $$R_E=\frac1N\sum_{i=1}^N\begin{cases}\sigma_i^{a_*}\prod_{j=1}^k\sigma_i^{a_j(E)},&\text{spin anchor},\\ \prod_{j=1}^k\sigma_i^{a_j(E)},&\text{marker anchor}.\end{cases}$$ $k=0$ 이면 이것은 각각 $R_{\{a_*\}}$ 와 $1$ 이다.

본문

확장 규칙 자체(old leaf 재사용 계수 1, fresh path 계수 $\gamma_\beta$)는 x:tree-extension-history에 있고, 원문은 그것을 lemma tree:extension-expansion의 이름으로 가리킨다. "anchor와 같지 않은 서로 다른 위치"는 anchor가 protected라 재사용되지 않고 고른 leaf가 다시 고를 수 없다는 규칙에서 온다. anchor (spin anchor, marker anchor), extension history 와 계수 $c_E$, mark 와 selector.

제약이 "anchor와 추가 color들로 이루어진 집합 안의 쌍"(추가 color끼리의 쌍 포함)으로 한정되는 이유(작성자 읽기): selector(pert:tree-identity.s2)는 mark 함수 $g_0,g_1,\ldots,g_k$ 를 통해서만 작동하고, mark 함수는 anchor(color 0)와 추가 color의 path에만 붙는다. old replica에는 mark 함수가 붙지 않으므로 그것과의 관계는 지정할 수 없다. §3의 x:tree-reference-paths도 같은 한정을 둔다.

$R_E$ 는 tree $\mathcal T_E$ 의 multioverlap $R_S$ (overlap)이다(spin anchor이면 anchor 포함). marker anchor에서 $k=0$ 이면 $R_E=1$ 이므로 그 경우의 항등식은 자명하다.

원문 (perturbations.tex:429-449)

perturbations.tex:429-449

429The anchor is called a \emph{spin anchor} when $S_0=\sigma_i$, and a
430\emph{marker anchor} when $S_0=1$.  Added colors are ordered
431$1,\ldots,k$; the anchor has color $0$.  They occupy distinct replica
432positions, none equal to the anchor, according to the canceled-anchor
433extension rule of Lemma~\ref{tree:extension-expansion}.  A constraint
434$\mathcal C$ prescribes any consistent collection of their pairwise
435split depths, involving only the added colors and the anchor.
436It imposes no extra restrictions involving the other old replicas.
437Let $\mathfrak E(\mathcal T,a_*,\mathcal C)$ be the allowed extension
438histories, with coefficients $c_E$ from that lemma.  For a history
439$E$, set
440\[
441 R_E=\frac1N\sum_{i=1}^N
442 \begin{cases}
443 \displaystyle\sigma_i^{a_*}\prod_{j=1}^k\sigma_i^{a_j(E)},
444       &\text{spin anchor},\\[2pt]
445 \displaystyle\prod_{j=1}^k\sigma_i^{a_j(E)},
446       &\text{marker anchor}.
447 \end{cases}
448\]
449For $k=0$ these are respectively $R_{\{a_*\}}$ and $1$.
