# 도구 보고서: 물리판(L2) 검사와 사이트 (2026-11-13)

고친 것: `tools/check.py`, `tools/common.py`, `tools/build.py`, `tools/export_artifact.py`, `tools/README.md`, `tools/tests/{fixture,test_check,test_build,test_verify}.py`, 이 파일. `layers/`, `cards/`, `SCHEMA.md`, `site/`, `build/artifact/`, `build/check-report.md` 는 건드리지 않았다(시험은 fixture와 `/tmp` 출력). 작업 시점에 `layers/L2.md` 는 아직 없었다.

## 1. 새 검사 "물리판" (`check.py`, 함수 `rep_l2`; 단면 검사 뒤, 용어 검사 앞)

L2.md 가 없으면 "해당 없음".

| 등급 | 내용 |
|---|---|
| 오류 | 본문(첫 `##` 앞 포함)에 나온 규칙 번호가 rules.md 에 있다. `P6′` 와 `P6` 는 별개. rules.md 가 없으면 보지 않고 참고만 적는다 |
| 오류 | `[[g:slug]]` 가 용어집에, `[[id]]`(`\|표시어` 허용)가 카드나 graph.json 노드에 있다 |
| 경고 | `##` 절마다 "이 절이 쓰는 규칙:" 줄이 있다 |
| 경고 | 그 줄의 규칙 집합 = 절 본문(그 줄 제외, `###` 포함)에 나온 규칙 집합. 다르면 "줄에만 / 본문에만"을 적는다. "없음"은 빈 집합 |
| 경고 | 규칙 번호도 `[[…]]` 링크도 없는 단락 |
| 경고 | 첫 줄이 `# L2 — 물리판` 이 아니다 / `##` 절이 없다 |
| 참고 | 절·단락 수와 (단락 경고 수), L2 본문이 한 번도 쓰지 않은 규칙 목록 |

규칙 번호 패턴은 `common.RULE_REF` = `(?<![A-Za-z0-9_\\])P\d+′?(?![A-Za-z0-9_′])`. 요청에 있던 `\bP\d+′?(?![\w′])` 는 `P4를`, `P4와` 처럼 한글 조사가 바로 붙으면 놓친다(파이썬에서 한글도 `\w`). 그래서 뒤쪽 금지를 영문·숫자·`_`·`′` 로 좁혔다. 단면(L1) 검사는 건드리지 않았다. 코드와 수식(`$…$`, `$$…$$`)은 먼저 지우므로 `$P_N$`, `` `P8` `` 은 세지 않는다.

"규칙·용어 밖 사용"의 기계적 근사(경고 d)의 기준:
- 단위: 빈 줄로 나뉜 단락, 목록은 최상위 항목마다(중첩 항목은 그 항목에 합침).
- 뺀다: 수식을 지우고 표지를 뺀 글자가 12자 미만인 것(소제목, 수식만 있는 블록), 끝이 `:` 인 목록 머리, 표, "이 절이 쓰는 규칙:" 줄, 첫 `##` 앞의 머리·바닥·기호.
- 단위 안에 규칙 번호나 `[[…]]`(`[[g:…]]` 포함)가 하나라도 있으면 통과.
- 소음 확인: 실제 L1.md 를 `##` 절 꼴로 바꾼 가짜 L2 로 돌렸더니 단락 9개 중 1개만 울렸고(변환으로 생긴 조각), 절 규칙 줄 불일치는 의도대로 잡혔다. 진짜 L2 가 나오면 단락 경고 수가 보고서 "참고" 줄에 나오므로 많으면 `check.py` 의 `L2_MIN_CHARS`(12)를 올리거나 단위를 "단락"으로만 좁히면 된다.
- 알려진 한계: 같은 단락 안에서 일부 문장만 규칙·링크가 없어도 통과한다. 단위가 단락이다. 용어 링크는 "처음 나올 때 한 번" 규율이라 `[[g:…]]` 만 있는 단락은 규칙이 없어도 통과로 본다.
- "용어" 검사도 layers 전부의 `[[g:…]]` 를 세므로, 용어집에 없는 `[[g:…]]` 는 두 검사에서 각각 나온다(같은 줄, 이름만 다름).

## 2. `build.py`

- `layers/L2.md` 가 있으면 `L2.html` 을 L0·L1과 같은 방식으로 낸다(`[[g:…]]` 말풍선, `[[id]]` 카드 링크). 끝에 "여기서 더 내려가기" 줄(규칙 표, 용어집, 섹션 표, 카드 목록). 없으면 쪽·메뉴·첫 화면 항목을 모두 만들지 않는다.
- 규칙 번호 링크: 규칙 표의 행에 `<tr id="rule-P4">`(프라임은 `rule-P6p`)을 달고, L0·L1·L2 쪽의 맨 `P4`·`[P4](rules.md)` 를 `rules.html#rule-P4` 로 잇는다(`title` 에 규칙의 물리 문장). 규칙 표에 없는 번호는 붉은 물결 표시. 규칙 표 쪽 자체와 수식·코드 안은 그대로. 이 변경은 L0·L1에도 적용된다(실제 데이터: L0 3곳, L1 8곳이 링크되고 깨진 링크 0).
- 첫 화면: "위에서부터 읽기" 위에 `L0 → L1 → L2 → 섹션 카드(아래 표) → 노드 카드` 줄과 L2 항목. 메뉴에 L2.
- `export_artifact.py`: 쪽 순서와 메뉴에 L2 를 넣는다. 한 파일에서는 쪽 안 앵커가 없어 규칙 링크가 규칙 표 쪽 맨 위로 간다.
- `verify_site.py`: 사이트의 모든 `.html` 을 열기 때문에 코드 변경 없이 `L2.html` 도 돈다. 시험으로 확인.
