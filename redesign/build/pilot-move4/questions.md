# 시범(수 4) 독자 시험 질문지

대상: L2 §6(수 4)과 규칙 P6·P6′·P7. 같은 질문지를 개정 전(v0)과 개정 후(v1)에 쓴다.
독자에게는 질문지와 L0·L1·L2·rules·glossary만 준다. 카드와 원문은 주지 않는다.

답마다 (a) 답, (b) 근거 위치(파일과 절·행), (c) 출처 종류 — "글에 적혀 있음" / "글에서 추론함" / "추측함" / "찾지 못함" — 를 적는다.

1. **주 식.** P6′이 주장하는 주 식을 써라. 좌변이 무엇의 무엇인지(어떤 기대값을 어떻게 미분하는지), 우변의 합이 무엇에 대한 것이고 각 항이 무엇인지 말하라.
2. **$c_E$ 의 정의.** extension history $E$ 와 계수 $c_E$ 를 정의하라. 한 걸음의 선택지, 각 선택지의 계수, 계수 속 $n_\beta$ 가 정확히 무엇의 자식 수인지.
3. **계산.** old tree가 anchor $a_*$ 와 다른 replica $b$ 둘이고 깊이 $s$($0\le s\le L-1$)에서 갈라진다. $k=1$, $H=1$, $D=1$, $m_0=0$, $m_L=1$ 이다. 가능한 history를 모두 나열하고 각 $c_E$ 를 쓰고 합을 구하라. 그 합이 P6′ 좌변의 값과 맞는지 확인하라.
4. **anchor.** 왜 anchor leaf의 삽입 인자만 상쇄한 기대값을 보는가. 이 좌변이 P7의 어떤 양과 어떻게 이어지는가.
5. **모양별 총합.** $\kappa(S)$ 는 무엇들의 계수 합인가. 왜 old tree와 무관한가. anchor와 새 replica 하나가 깊이 $d$ 에서 갈라지는 모양 $S$ 의 $\kappa(S)$ 를 구하고 격자 $m_d=d/L$ 에서의 값을 써라.
6. **P7.** P7의 식에서 $f$, $R_E$, $c_E$, 두 합의 범위가 각각 무엇인지, 식을 말로 하면 무슨 뜻인지, 어떤 극한에서 성립하는지.
7. **흐름.** 수 4가 앞의 수들에서 받는 것과 수 5에 넘기는 것.
8. **계수 한계.** 무엇이 $\delta^b$ 크기로 작고, 무엇이 $L$ 에 균일하게 유계인가.
9. **막힌 곳.** 읽다가 막힌 곳, 정의 없이 나온 기호, 다시 읽어야 했던 문장을 모두 적어라.
