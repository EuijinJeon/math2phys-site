## 3. 검산 기록 (손 계산)

- **예 3, anchor 하나** ($L=1$, $k=2$, $G=1$, $D_1=D_2=1$). 좌변: $A$ 상수라 $K^A=K$, $E^A[1/A^{a_*}]=(1+t_1+t_2)^{-1}$, $\partial_1\partial_2=2(1+t_1+t_2)^{-3}\rvert_0=2$. 우변: root fresh $m_0-1\cdot m_1=-1$, 그 뒤 root 자식 2개라 $m_0-2m_1=-2$. $c_E=2$. 맞음. 일반 $D_j$ 로도 좌변 $2\langle D_1\rangle\langle D_2\rangle$, 우변 $2\langle D_1\rangle\langle D_2\rangle$(독립 replica 셋).
- **예 3, anchor와 $a'$** (root에서 갈라짐). 재사용→fresh $(+1)(-2)$, fresh→재사용 $(-2)(+1)$, fresh→fresh $(-2)(-3)$. 합 $2$. 맞음. 둘째 걸음 자식 수를 old tree에서 세면 각각 $1$, $-2-2+4=0$ 으로 틀린다. $k=1$ 판(재사용 $+1$, fresh $-2$, 합 $-1$)은 예 1의 $L=1$, $s=0$ 과 같다.
- **telescoping 한 줄**: $\sum_\beta(n_\beta m_{d_\beta+1}-m_{d_\beta})$ 에서 root 아닌 vertex는 자식으로 한 번 $+m$, 내부 vertex는 한 번 $-m$. 남는 것 $\lvert\mathcal T\rvert m_L-m_0=\lvert\mathcal T\rvert$. 부분 tree(뿌리 깊이 $d+1$, leaf $q$ 개)에서는 $\sum\gamma=m_{d+1}-q$, 재사용 $q$ 를 더해 $m_{d+1}$(trees.tex 368–371).
- **polarization $k=2$**: 원문 공식 $\frac{k^k}{2^kk!}\sum_\epsilon(\prod\epsilon_j)Q(k^{-1}\sum\epsilon_jg_j)$ 에 $k=2$ 를 넣으면 계수 $1/2$, $Q$ 의 짝수성으로 $Q(\frac{g_1+g_2}2)-Q(\frac{g_1-g_2}2)$. $Q(x)=B(x,x)$ 이면 $=\frac14[B(g_1+g_2,g_1+g_2)-B(g_1-g_2,g_1-g_2)]=B(g_1,g_2)$. $B$ 는 $A=1+z_1g_1\sigma_i+z_2g_2\sigma_i$ 의 혼합 미분이고 $B(g,g)=\partial_t^2$($A=1+tg\sigma_i$)$=2[t^2]$. 맞음.
- **단계 3 부등식**: perturbations.tex 410–417. 첫째 항 $\le\lVert f\rVert e_{\nu,N}\to0$($j$ 고정), 둘째 항 $\le C\cdot2j^{-j}$, $C$ 는 $N$, 선택된 매개변수, $j$ 에 무관(395–399).
- **하한 반례**: 균등 격자 $d_v=0$, $a_v=3$: 인자 $(m_0-m_1)(m_0-2m_1)=(-\delta)(-2\delta)=2\delta^2$, $\delta^1$ 보다 작다. 일반: $\lvert m_d-jm_{d+1}\rvert=(j-1)m_d+j\delta$(trees.tex 451–452).
- **$\lvert J_{\rm sep}\rvert\le k^k\delta^{b_{\rm sep}}$** (작성자 산수 유지): 모양 $S$ 의 leaf가 $k+1$ 개라 $\sum_{\text{모든 }v}(a_v-1)=k$, 그래서 고른 vertex의 $j\ge2$ 인자 수 $\sum(a_v-2)\le k-b_{\rm sep}$, 각 $\le j\le k$.

## 5. 용어집·§7·질문지에 넘길 것 (고치지 않음)

1. **§7.3** "P7의 두 번째 항등식" → "marker anchor($S_0=1$)로 쓴 P7의 항등식"(정확성 지적 8).
2. **§7.2** $S^+$ 의 정의를 §7.2 본문에도 한 구절(D17). §6.2 ③ 기호 주의와 같은 말로.
3. **용어집 기호 칸**: `g:palm-identity` 에 $\Pi_{N,\mathcal T}=J_{N,\mathcal T}$, $\Xi_N=H_N$; `g:protected-leaf` 에 $G$/$H$ 관계; `g:depth-delay` 의 $C_{k,\eta}$ 와 L2의 $C_{q,k,\eta}$ 관계(원문 decorrelation.tex 351은 $C_{k,\eta}$, trees.tex 412는 $C_{q,k,\eta}$; old tree가 $S$ 두 벌로 정해지면 $q$ 가 $k$ 로 정해짐), $S^+$ 정의; `g:multioverlap` 에 L2 §6의 $R_U$ 별칭; `g:extension-history` 에 "$n_\beta$ 는 그 걸음 직전 현재 tree의 자식 수"(v1 노트 5절 제안 1, R11).
4. **용어집 `g:tree-law`**: leaf 수 기호를 $\lvert\mathcal T\rvert$ 로 맞출지 결정.
5. **질문지**: 다음 시험은 $G$, $a'$ 기호로 맞추고, 천장 효과를 피하려면 예 3 꼴이 아닌 $k=2$ 문항(예: old leaf 둘이 깊이 $s$ 에서 갈라진 $L=2$ 의 $k=2$), 부분 tree 합 $m_{d+1}$ 의 이유, 단계 3 부등식 문항을 넣는다(grade-v1 0절).
6. **"일관"의 정의**(R4)는 원문 "consistent"의 읽기다. 용어집에 `g:topology` 또는 `g:tree-identity` 뜻 칸에 같은 말을 둘지 결정.
