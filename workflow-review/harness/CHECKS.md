# 구현 검증 기록

2026-11-17 (한국 시간). 대상: 로컬 기록 하네스 0.1.

- `make check-graph-harness`: 문법 검사와 동작·결함 검사 12종 통과.
- 실제 예제 생성 run과 수정 run 실행: 기록 검사 오류·미종료 경고 0.
- 예제 수정에서 없는 edge 끝을 검사기가 거부하고 exit code 1 반환. 실패 기록을 보존한 채 복구와 재검사(exit code 0)를 별도 step/attempt로 남김.
- 생성·수정 전후 파일의 해시가 보존되며, 파일 변조와 event 삭제를 검사기가 탐지함.
- 없는 output 참조, 실패 결과의 완료 승격, 미종료 run 완료, 기존 run 덮어쓰기, 종료 run에 실행 추가, 동시 writer를 거부함.
- annotation 추가 전후에 기존 event 바이트가 유지됨. 삽입한 HTML은 검토 화면에서 텍스트로 escape됨.
- 로컬 브라우저: 전체 과정 → 수정 단계 → 반환 event → 전체 과정 복귀 확인. 출력 참조의 event 링크가 세부 화면을 숨기는 문제를 발견해 수정 후 다시 확인함.

이 파일럿은 사전에 작성한 예제다. LLM 독립 세션 시험, 모든 도구의 자동 기록, 수학적 내용 검증, 공개 지도 형식 통합은 아직 하지 않았다. raw 기록·스냅샷·검토 HTML은 gitignore된 .local/에만 보관한다. 이 문서는 공개 가능한 검증 요약이며 원본 로그를 포함하지 않는다.
