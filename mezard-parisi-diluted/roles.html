    물리 역할 지정 — The Mézard–Parisi formula for diluted spin glasses¶

    수학적 object에 사용자가 부여한 물리적 역할. 해석은 이 지정을 따른다. 상태: 확정(사용자 확정) / 제안 해석(미확정, 에이전트 제안) / 폐기. 변경 이력은 맨 아래에 남긴다. 변경 시 영향 문단은 scripts/find_refs.py로 찾는다.

    ID 수학 object 정의 위치 지정된 물리 역할 상태 정합성 점검 (부호·차원·극한) 근거
    R1 \(\theta(s_1,\ldots,s_p)\) §2 ¶1 \(p\)-body factor(clause)의 log Boltzmann weight, \(\theta=-\beta\,\varepsilon(s)\) (\(\beta\) 흡수) 제안 해석 \(-H_N=\sum_k\theta_k+\dots\), \(Z=\sum e^{-H}\) 이므로 \(\theta\) 큰 배치가 선호됨 ✓ 논문 식 (2.2)
    R2 \(h,\ h_i\) §2 ¶1 random external field (\(\beta h\) 흡수) 제안 해석 \(e^{h\sigma}\) ✓ (2.2)
    R3 \(\alpha\), \(M_N\sim\mathrm{Poisson}(\alpha N)\), \(i_{\ell,k}\) §2 ¶1 (a) 상호작용 밀도 = spin 당 평균 factor 수 (K-SAT 의 clause density). Poisson random hypergraph(Erdős–Rényi factor graph). spin 하나의 평균 degree \(=\alpha p\) 제안 해석 \(\mathbb E M_N/N=\alpha\), degree 평균 \(p\alpha\) ↔ (2.8)의 \(k\sim\mathrm{Poisson}(\alpha p)\) ✓ (2.2), (2.8)
    R4 \(F_N=\frac1N\mathbb E\log Z_N\) (2.2) pressure (quenched) \(=-\beta f\), \(f\)=free energy density 제안 해석 논문이 직접 "pressure", "free energy 는 그 음수를 \(\beta\) 로 나눈 것"이라 명시 ✓ §1 ¶1
    R5 \(e^{\theta}=a(1+b\prod_\ell f_\ell(s_\ell))\) (2.3) (2.3) factor weight 의 high-temperature(tanh/loop) 전개: \(a\)=spin 무관 정규화, \(b\)=effective coupling(bond 의 \(\tanh\)), \(f_\ell\)=spin 의 국소 관측량 확정 Viana–Bray: \(e^{\beta J s_1s_2}=\cosh\beta J\,(1+\tanh\beta J\,s_1s_2)\) → \(a=\cosh\beta J\), \(b=\tanh\beta J\), \(f=s\) ✓ (pilot 에서 ✅ 예정) (2.3), Franz–Leone [9]
    R6 조건 \(\mathbb E[(-b)^n]\ge0\) (2.4) (2.4) interpolation 의 나머지항 부호를 고정하는 조건 (even \(p\) 와 함께 상한의 부호를 보장). 물리적으로는 "frustration 이 대칭적이거나 반강자성 쪽"이라는 coupling 분포 조건 제안 해석 대칭 \(J\): 홀수 moment 0, 짝수 moment \(\ge0\) ✓; soft K-SAT: \(b\lt 0\) ✓ Franz–Leone [9], PT [16]
    R7 message \(x\), \(q_x(s)=e^{xs}/2\cosh x\) §2.1 ¶2 cavity field (\(\beta\) 단위): 이웃을 떼어낸 spin 이 느끼는 유효 국소장, \(\langle s\rangle_{q_x}=\tanh x\) 확정 \(q_x\) 는 정규화된 확률 ✓ §2.1 ¶1 s2
    R8 \(U_\theta(x_1..x_{p-1};\varepsilon)\) (2.6) (2.6) factor→spin cavity bias (\(u\)-message): 나머지 \(p-1\) spin 이 cavity field 로 주어졌을 때 factor 가 새 spin \(\varepsilon\) 에 주는 log-weight 제안 해석 \(\lvert U\rvert\le B(\theta)\) ✓ (2.6)
    R9 \(C_\theta(x_1..x_p)\), \(V_{\rm e}\) (2.5),(2.9) (2.5) Bethe free entropy 의 factor(edge) 항: cavity field 속 \(p\) spin 에 factor 하나를 다시 붙일 때의 partition function 제안 해석 계수 \(-\alpha(p-1)\) 는 factor graph Bethe 공식의 이중계수 보정 (pilot 에서 ✅ 예정) (2.11), MP [12]
    R10 \(V_{\rm s}\) (2.8) (2.8) Bethe free entropy 의 site 항: 새 spin 하나를 Poisson\((\alpha p)\) 개 factor 와 field 로 삽입할 때의 partition function 제안 해석 \(\tfrac12\sum_\varepsilon\) 와 \(\log2\) 가 짝 ✓ (2.8), (2.11)
    R11 \(r\), \(\zeta\in\mathcal M_{r+1}\), chain \(\eta_0\to\dots\to x\) (2.7) (2.7) \(r\)-step RSB order parameter: \(r=0\) RS 의 cavity field 분포 \(P(h)\), \(r=1\) 1RSB 의 "분포의 분포"(population of populations), 깊이 \(d\) = state 계층의 단계 제안 해석 \(\mathcal M_1=\mathcal P(\mathbb R)\) = RS ✓ §2.1 ¶3, spin-glass 사전
    R12 \(0\lt m_1\lt\dots\lt m_r\lt 1\) §2.1 ¶3 Parisi parameter (RPC 파라미터, overlap 분포의 누적값 \(x(q)\) 의 계단 높이) 확정 \(m\to1\), \(m\to0\) 극한이 각각 annealed·quenched 평균 ✓ (pilot 에서 ✅ 예정)
    R13 power mean \(T_d\) (2.10) (2.10) pure state 계층에 대한 Ruelle cascade 평균을 적분해 낸 형태 확정 \(T_d\) 는 \(V\) 의 곱셈적 상·하한을 보존 ✓ (2.10), PT [16] §5
    R14 \(\mathscr F_d\), message label \(\omega\) §2.1 ¶3 🔧 기술 장치 (계층 \(d\) 단계까지의 정보, 독립 사본 표지) 제안 해석
    R15 \(\mathcal B_r(\zeta,\mathbf m)\) (2.11) (2.11) \(r\)RSB Bethe(Mézard–Parisi) free entropy functional — 시행 order parameter 에서의 pressure 예측값 제안 해석 \(r=0\) 이면 RS Bethe free entropy ✓ (2.11), MP [12]
    R16 \(\Phi_r=\inf\mathcal B_r\), \(\inf_r\Phi_r\) (2.13) (2.11),(2.13) 물리의 "saddle point(극값) 선택"에 대응하는 변분 원리. 단 수학은 각 시행값이 상한이므로 inf 확정 🧭 물리(정류점) vs 수학(inf) 차이를 해석에 표시 Theorem 2.1
    R17 tree 계수 \(\gamma_\beta=m_{d}-n_\beta m_{d+1}\), \(\kappa(S)\) (3.5),(3.13) §3.1 ¶7 replica trick 의 Parisi block counting (\(n\to0\)): 크기 \(m_d\) block 에서 replica 가 있는 sub-block \(n_\beta\) 개를 뺀 자리 수 제안 해석 RS(\(L=1\))에서 \(\gamma=-n\), \(\kappa=(n-1)\cdots(n-k)\vert_{n=0}=(-1)^kk!\) ✓; (3.12) 무작위 tree brute force ✓ MPV 의 Parisi 행렬, §3.1 ¶7 전개
    R18 tree 법칙 \(Q_k\) (3.8) §3.2 ¶2 Ruelle cascade 에서 뽑은 \(k\) 개 replica 의 overlap tree 법칙 (nested Chinese restaurant) 제안 해석 \(L=2\): PD\((m,0)\) CRP 와 규칙 일치 ✓, \(Q_2\) split 확률 \(m_{d+1}-m_d=P(q_d)\) ✓, (3.9) sympy 정확 일치 ✓ Pitman (2006) §3.2, PT [16]
    R19 path kernel \(K_d\), tilted kernel (3.2) §3.1 ¶4 계층 \(d\) 에서 하위 상태를 고르는 확률; tilt = 상태 가중치 \(\propto Z_\alpha^{m_d}\) (Monasson \(m\)-reweighting) 제안 해석 확률 kernel 정규화 ✓, \(L=2\) 에서 \(K_1\propto P(\alpha)Z_\alpha^m\) ✓ §3.1 ¶4 전개
    R20 삽입 \(A\), \(Y_d\) (3.3), \(\log Y_0\) §3.1 ¶5 Boltzmann 가중치 섭동 (\(-\delta H=\log A\)); \(\log Y_0\) = 계층 free entropy 변화 제안 해석 \(L=1\): \(\log Y_0=\log Z_A/Z\) ✓, \(L=2\): 1RSB replicated free entropy 차 ✓ §3.1 ¶5 전개, Lemma 3.1
    R21 mark (Rademacher 좌표, 깊이 \(d\)), selector (6.18) §6.1 ¶1 상태 계층의 깊이 \(d\) 묶음마다 무작위 부호를 갖는 국소 field — replica 쌍의 상관으로 overlap 단계를 탐지 제안 해석 공유 vertex 에서 \(\mathbb E\xi^2=1\), 아니면 0 ✓ §6.5 ¶4 전개
