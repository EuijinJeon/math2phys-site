    §8 Independent hierarchical messages and the cavity comparison¶

    제목: 독립 계층 message 와 cavity 비교

    ← 이전: §7 Decorrelation on prescribed trees · 목차 · 다음: §9 Normalization, truncation, and completion of the proof →

    섹션 요약 — 무엇을 하는지 · 물리적 의미 · 건너뛰어도 되는지

    하는 일. lower bound 를 완성한다 (유계 모형). - Lemma 8.1: 섭동된 reservoir 의 무작위 site 하나에 대해, 상태 계층 안의 local field \(x=\operatorname{arctanh}\langle\sigma_i\rangle\) 의 계층적 분포를 RSB order parameter \(\zeta_{L,N}\in\mathcal M_L\) 로 encode. 시행 message 의 spin moment = 실제 multioverlap 평균 (8.2). - Lemma 8.2: site 패턴의 경험 분포는 multioverlap 으로 결정 → multioverlap 이 집중하면 서로 다른 site 를 독립 message 로 바꿀 수 있다. - Proposition 8.3: §3 의 log 전개 + §7 의 집중 + Lemma 8.2 로, cavity 증분 \(\Delta_N\approx\mathcal B_{L-1}(\zeta_{L,N},\mathbf m^{(L)})\). - Corollary 8.4: \(\liminf F_N\ge\inf_r\Phi_r\).

    물리적 의미. cavity method 의 논리 — "실제 계의 cavity field 분포(population of populations)를 order parameter 로 넣으면 Bethe 공식이 free energy 를 준다" — 를 엄밀화. 핵심 단계인 "cavity spin 들이 독립" 은 §7 의 multioverlap 집중으로 정당화된다. 물리와 달리 고정점 방정식은 필요 없다: 실제 계에서 읽은 order parameter 는 하나의 시행일 뿐이고, 그 Bethe 값이 inf 보다 크다는 것만 쓴다.

    건너뛰어도 되는지. 결론 Corollary 8.4 만 알면 된다: (유계 모형에서) pressure 의 liminf \(\ge\inf_r\Phi_r\). §4 의 upper bound 와 합쳐 Mézard–Parisi 공식이 된다 (§9 에서 유계 가정 제거).

    §8 ¶1¶

    원문

    s1 We turn the reservoir into a trial law in three steps: encode its full one-site branching law, use multioverlap concentration to separate the sites, and compare the resulting insertion logarithms.

    번역

    s1 reservoir 를 세 단계로 시행 법칙으로 바꾼다: 그 단일 site branching 법칙 전체를 encode 하고, multioverlap 집중을 써서 site 들을 분리하고, 결과로 나오는 삽입 log 들을 비교한다.

    물리 해석

    • s1 lower bound 의 핵심 아이디어: 실제 계(reservoir)의 상태 구조 자체를 하나의 RSB 시행 법칙으로 읽는다. 그러면 cavity 증분 ≈ 그 시행 법칙의 Bethe 값 \(\ge\inf\mathcal B\). 물리의 cavity method 에서 "실제 계의 cavity field 분포(population)가 RSB order parameter" 라는 것을 그대로 엄밀화. 📚 [2], [14]

    §8 ¶2¶

    원문

    s1 Fix \(\varepsilon\gt 0\).

    s2 At each depth \(L\ge2\), use the sequence of sizes and deterministic parameter choices supplied by Lemma 6.2.

    s3 Write \(N\) for sizes on this sequence.

    s4 The choices may depend on \(L\), and all statements below concern these choices.

    s5 Retain \(\underline F\) for the liminf over all system sizes of the bounded model, as before selection.

    s6 In particular,

    \[ \Delta_N^{L,\mathbf u_{L,N}}\le\underline F+2\varepsilon. \tag{8.1} \]

    번역

    s1 \(\varepsilon\gt 0\) 을 고정한다.

    s2 각 깊이 \(L\ge2\) 에서 Lemma 6.2 가 주는 크기 수열과 결정적 매개변수 선택을 쓴다.

    s3 이 수열 위의 크기를 \(N\) 이라 쓴다.

    s4 선택은 \(L\) 에 의존할 수 있으며, 아래의 모든 명제는 이 선택들에 관한 것이다.

    s5 \(\underline F\) 는 선택 이전과 마찬가지로 유계 모형의 모든 계 크기에 대한 liminf 로 유지한다.

    s6 특히 다음이 성립한다.

    물리 해석

    • s1–s6, (8.1) 🔧 선택된 크기들에서 cavity 증분이 \(\underline F+2\varepsilon\) 이하 (Lemma 6.2 (i)).

    §8.1 Encoding a single-site tree¶

    제목: 단일 site tree 의 encoding

    ▸ Lemma 8.1 (Recursive law encoding)¶

    §8.1 ¶1¶

    원문

    s1 For each fixed \(N\), \(L\ge2\), and selected parameter vector, with the reservoir root disorder averaged, there is a deterministic trial law \(\zeta_{L,N}\in\mathcal M_L\) whose single-label spin process has the same expected spin products on every prescribed tree as a uniformly chosen site of the reservoir.

    s2 Different trial labels can be chosen independently.

    번역

    s1 각 고정된 \(N\), \(L\ge2\), 선택된 매개변수 벡터에 대해, reservoir root disorder 를 평균하면, 그 단일 label spin 과정이 모든 지정된 tree 위에서 reservoir 의 균등하게 고른 site 와 같은 기대 spin 곱을 갖는 결정적 시행 법칙 \(\zeta_{L,N}\in\mathcal M_L\) 이 존재한다.

    s2 서로 다른 시행 label 은 독립적으로 고를 수 있다.

    물리 해석

    • s1–s2 Lemma 8.1: reservoir 의 "무작위 site 하나가 상태 계층 안에서 갖는 local field 의 계층적 분포" 를 RSB order parameter \(\zeta\in\mathcal M_L\) (R11) 로 encode. 물리: population dynamics 에서 쓰는 cavity field 의 분포의 분포 가 실제 계에서 바로 정의된다. 📚 증명 §8.1 ¶2–¶4

    (끝: s8-1-e1)

    ▸ Proof.¶

    §8.1 ¶2¶

    원문

    s1 Include an independent uniform site \(i\in[N]\) in the root variable, along with the reservoir root disorder.

    s2 Sample the tilted reservoir auxiliary kernels along each path, and let \(\mathscr G_d\) be the sigma-field generated by this enlarged root and the full auxiliary prefix through depth \(d\).

    s3 At depth \(r=L-1\) put

    \[ x=\operatorname{arctanh}\langle{\sigma_i}\rangle, \]

    ↳ where the brackets denote the leaf Gibbs expectation.

    s4 This is finite: at finite \(N\) all configuration weights are strictly positive, so \(-1\lt \langle{\sigma_i}\rangle\lt 1\).

    s5 Thus \(x\) is determined at depth \(r\), before the terminal spin transition at depth \(L\).

    s6 At each terminal replica leaf, draw a spin with law \(q_x\).

    s7 Given the auxiliary prefix, these spins are independent and have exactly the one-site law of the independent terminal Gibbs replicas.

    번역

    s1 root 변수에 reservoir root disorder 와 함께 독립 균등 site \(i\in[N]\) 을 포함한다.

    s2 각 경로를 따라 tilted reservoir 보조 kernel 을 뽑고, \(\mathscr G_d\) 를 이 확대된 root 와 깊이 \(d\) 까지의 보조 prefix 전체로 생성되는 sigma-field 라 하자.

    s3 깊이 \(r=L-1\) 에서 다음과 같이 두며, 괄호는 leaf Gibbs 기댓값을 뜻한다.

    s4 이것은 유한하다: 유한 \(N\) 에서 모든 배치 가중치는 엄격히 양수이므로 \(-1\lt\langle{\sigma_i}\rangle\lt 1\) 이다.

    s5 따라서 \(x\) 는 깊이 \(L\) 의 말단 spin 전이 이전인 깊이 \(r\) 에서 결정된다.

    s6 각 말단 replica leaf 에서 법칙 \(q_x\) 를 갖는 spin 을 뽑는다.

    s7 보조 prefix 가 주어지면 이 spin 들은 독립이고 독립 말단 Gibbs replica 들의 단일 site 법칙을 정확히 갖는다.

    물리 해석

    • s3, \(x=\operatorname{arctanh}\langle\sigma_i\rangle\) = site \(i\) 의 pure state 안에서의 local field (R7 cavity field 의 정의 \(\langle s\rangle_{q_x}=\tanh x\) 를 거꾸로). 물리: 상태 \(\alpha\) 안 자화 \(m_i^\alpha=\tanh h_i^\alpha\) 에서 field \(h_i^\alpha\) 를 읽음. ✅ 아래 전개
    • s6–s7 상태가 정해지면 같은 site 의 replica spin 들은 \(q_x\) 로 독립 — 같은 pure state 의 두 replica 는 site 하나에서 자화만 공유. ✅ 아래 전개
    전개: local field 의 정의와 단일 site 법칙 (s3–s7)

    \(q_x(s)=e^{xs}/(2\cosh x)\) 이면 \(\sum_ssq_x(s)=\tanh x\). \(x=\operatorname{arctanh}\langle\sigma_i\rangle\) 로 두면 \(\langle s\rangle_{q_x}=\langle\sigma_i\rangle\) ✓. \(\pm1\) spin 의 법칙은 평균으로 결정되므로 \(q_x\) = 상태 안 \(\sigma_i\) 의 법칙 ✓. 깊이 \(L\) 에서 replica 들은 prefix 가 주어지면 독립이므로 각자 \(q_x\) ✓.

    식 Eq. §8.1 ¶2 #1 항별 표

    항 수학적 정의 지정된 물리 역할 하의 의미 검증
    \(x=\operatorname{arctanh}\langle\sigma_i\rangle\) 깊이 \(r\) 변수 site \(i\) 의 pure state 안 local field (R7) ✅ 같은 문단 전개

    §8.1 ¶3¶

    원문

    s1 Define the random measures backward by

    \[ \eta_{r-1}=\operatorname{Law}(x\mid\mathscr G_{r-1}),\qquad \eta_d=\operatorname{Law}(\eta_{d+1}\mid\mathscr G_d) \quad(0\le d\lt r-1). \]

    s2 Then \(\eta_d\in\mathcal M_{r-d}\), so \(\zeta_{L,N}=\operatorname{Law}(\eta_0)\in\mathcal M_L\).

    s3 All state spaces are standard Borel, so these conditional probability kernels have measurable versions.

    s4 The auxiliary priors used here may be taken to be finite products of finite mark spaces at each realized root; hence the same assertion also follows directly by finite sums conditional on the root counts.

    번역

    s1 무작위 측도들을 거꾸로 다음과 같이 정의한다.

    s2 그러면 \(\eta_d\in\mathcal M_{r-d}\) 이므로 \(\zeta_{L,N}=\operatorname{Law}(\eta_0)\in\mathcal M_L\) 이다.

    s3 모든 상태 공간이 standard Borel 이므로 이 조건부 확률 kernel 들은 측정가능한 판본을 갖는다.

    s4 여기서 쓰는 보조 prior 는 각 실현된 root 에서 유한 mark 공간들의 유한 곱으로 잡을 수 있다; 따라서 같은 주장은 root 개수에 조건부인 유한 합으로도 직접 나온다.

    물리 해석

    • s1–s2 \(\eta_{r-1}\) = 깊이 \(r-1\) 상태 묶음 안에서 local field 의 분포, \(\eta_{r-2}\) = 그 분포들의 분포, … → \(\zeta\) = 최상위 분포. 물리: 1RSB 이면 \(\zeta\) = "상태마다 다른 cavity field 분포(population)의 분포" — Mézard–Parisi 의 population of populations 그대로 (R11). 📚 [12]
    • s3–s4 🔧 측정가능성.

    식 Eq. §8.1 ¶3 #1 항별 표

    항 수학적 정의 지정된 물리 역할 하의 의미 검증
    \(\eta_{r-1}=\mathrm{Law}(x\mid\mathscr G_{r-1})\) 가장 안쪽 측도 한 상태 묶음 안의 local field 분포 📚 R11
    \(\eta_d=\mathrm{Law}(\eta_{d+1}\mid\mathscr G_d)\) 거꾸로 쌓기 분포의 분포 (계층) 📚 R11

    §8.1 ¶4¶

    원문

    s1 Here is an explicit verification for every branching pattern.

    s2 Fix a descendant tree \(T\) and prescribe a spin \(e_a\) at each terminal leaf.

    s3 At depth \(r\), its conditional probability is \(G_T(x)=\prod_a q_x(e_a)\).

    s4 At depth \(d\lt r\), let \(T_1,\ldots,T_j\) be the subtrees rooted at its children.

    s5 Conditional independence of children gives the backward recursion

    \[ G_T(\eta_d)=\prod_{\ell=1}^j \int G_{T_\ell}(\nu)\,\eta_d(d\nu). \]

    s6 By induction, this probability depends on the full prefix only through \(\eta_d\).

    s7 Thus the nested measures preserve the joint output law of every descendant tree, including unary stretches and arbitrary numbers of children.

    s8 This recursion is precisely the branching version of (2.7).

    s9 Taking \(\zeta_{L,N}=\operatorname{Law}(\eta_0)\) preserves the root mixture as well.

    s10 In particular, for every subset \(S\) of the leaves,

    \[ \mathbb E\prod_{a\in S}\tau^a =\frac1N\sum_{i=1}^N\mathbb E\prod_{a\in S}\sigma_i^a =\mathbb E R_S. \tag{8.2} \]

    s11 Use independent copies of the entire construction, including the reservoir root and uniform site, for different labels.

    s12 The resulting messages are independent of the new physical disorder in the cavity insertions.

    번역

    s1 모든 branching 패턴에 대한 명시적 확인은 다음과 같다.

    s2 자손 tree \(T\) 를 고정하고 각 말단 leaf 에 spin \(e_a\) 를 지정한다.

    s3 깊이 \(r\) 에서 그 조건부 확률은 \(G_T(x)=\prod_a q_x(e_a)\) 다.

    s4 깊이 \(d\lt r\) 에서 \(T_1,\ldots,T_j\) 를 그 자식들에 뿌리를 둔 subtree 라 하자.

    s5 자식들의 조건부 독립성이 다음 backward 재귀를 준다.

    s6 귀납에 의해 이 확률은 전체 prefix 에 오직 \(\eta_d\) 를 통해서만 의존한다.

    s7 따라서 포개진 측도들은 unary 구간과 임의의 자식 수를 포함해 모든 자손 tree 의 결합 출력 법칙을 보존한다.

    s8 이 재귀는 정확히 (2.7) 의 branching 판이다.

    s9 \(\zeta_{L,N}=\operatorname{Law}(\eta_0)\) 로 잡으면 root 혼합도 보존된다.

    s10 특히 leaf 의 모든 부분집합 \(S\) 에 대해 다음이 성립한다.

    s11 서로 다른 label 에 대해서는 reservoir root 와 균등 site 를 포함한 전체 구성의 독립 사본을 쓴다.

    s12 결과로 나오는 message 는 cavity 삽입의 새 물리적 disorder 와 독립이다.

    물리 해석

    • s2–s9 재귀 \(G_T(\eta_d)=\prod_\ell\int G_{T_\ell}\,d\eta_d\): 서로 다른 하위 상태로 가는 replica 무리는 독립적으로 하위 상태를 뽑는다 — RPC 계층의 표본추출 규칙 그대로. 그래서 encode 된 \(\zeta\) 가 원래 replica 결합 법칙을 보존. ✅ 아래 전개
    • s10, (8.2) 시행 message 의 spin moment = reservoir 의 multioverlap 평균. 즉 시행 order parameter 가 실제 계의 모든 multioverlap 평균을 재현. ✅ 아래 전개
    전개: (8.2) (s10)

    균등 site \(i\) 가 root 에 포함되어 있으므로 \(\mathbb E\prod_{a\in S}\tau^a=\mathbb E_i\mathbb E\prod_a\sigma_i^a=\frac1N\sum_i\mathbb E\prod_{a\in S}\sigma_i^a\) ✓, 그리고 \(\frac1N\sum_i\prod\sigma_i^a=R_S\) (3.1) ✓. 재귀: 깊이 \(d\) 의 자식 subtree 들은 prefix 가 주어지면 독립 (tree 표본추출 규칙) → 확률이 곱, 각 자식 subtree 는 다음 단계 측도 \(\nu\sim\eta_d\) 를 통해서만 의존 ✓.

    식 Eq. §8.1 ¶4 #1 항별 표

    항 수학적 정의 지정된 물리 역할 하의 의미 검증
    \(G_T(\eta_d)=\prod_\ell\int G_{T_\ell}(\nu)\eta_d(d\nu)\) backward 재귀 서로 다른 하위 상태의 replica 무리는 독립 (RPC 표본추출) ✅ 같은 문단 전개

    식 (8.2) 항별 표

    항 수학적 정의 지정된 물리 역할 하의 의미 검증
    \(\mathbb E\prod_{a\in S}\tau^a\) 시행 message spin moment 시행 order parameter 가 예측하는 multioverlap ✅ 같은 문단 전개
    \(=\mathbb ER_S\) reservoir multioverlap 평균 실제 계의 multioverlap ✅

    §8.2 From multioverlaps to spin patterns¶

    제목: multioverlap 에서 spin 패턴으로

    ▸ Lemma 8.2 (Empirical-pattern comparison)¶

    §8.2 ¶1¶

    원문

    s1 Fix a prescribed tree with \(k\) leaves.

    s2 Suppose an observable of absolute value at most one uses the replica-spin patterns at \(a\) independent uniform site labels.

    s3 Replacing these patterns by \(a\) independent trial-label patterns from Lemma 8.1 changes its expected value by at most

    \[ a\sum_{\varnothing\ne S\subseteq[k]}\mathbb E|R_S-\mathbb E R_S|. \tag{8.3} \]

    s4 The observable may also depend on new insertion disorder, independent of the reservoir.

    번역

    s1 \(k\) 개 leaf 를 가진 지정 tree 를 고정한다.

    s2 절댓값이 1 이하인 관측량이 \(a\) 개의 독립 균등 site label 에서의 replica-spin 패턴을 쓴다고 하자.

    s3 이 패턴들을 Lemma 8.1 의 \(a\) 개의 독립 시행 label 패턴으로 바꾸면 그 기댓값이 최대 다음만큼 바뀐다.

    s4 관측량은 reservoir 와 독립인 새 삽입 disorder 에도 의존할 수 있다.

    물리 해석

    • s1–s4, (8.3) Lemma 8.2: 무작위 site \(a\) 개의 replica spin 패턴을 독립 시행 message 로 바꾸는 오차 ≤ \(a\times\)(multioverlap 들의 요동). 즉 multioverlap 이 self-averaging 이면 서로 다른 site 들이 독립 — cavity method 에서 cavity spin 들(삽입 factor 의 이웃)을 독립 message 로 다루는 것의 정당화. 📚 증명 §8.2 ¶2

    식 (8.3) 항별 표

    항 수학적 정의 지정된 물리 역할 하의 의미 검증
    \(a\sum_S\mathbb E\lvert R_S-\mathbb ER_S\rvert\) 패턴 교체 오차 site 사이 독립성 위반 = multioverlap 요동 📚 §8.2 ¶2

    (끝: s8-2-e3)

    §8.2 ¶2¶

    원문

    s3 이것이 기대 삽입 log 의 수렴을 증명한다: 명시적으로, 먼저 Poisson 꼬리를 통제하도록 \(M\) 을, 그 다음 기하 꼬리를 통제하도록 \(q\) 를 고르고, 남은 유한 개의 전개 항에 대해 \(N\) 과 \(L\) 의 극한을 취한다.

    s4 위의 시행 항등식과 (5.5) 와 함께 이것이 (8.6) 을 증명한다.

    물리 해석

    • s1–s4 🔧 극한 순서: \(M\) (degree cutoff) → \(q\) (전개 차수) → \(N\) → \(L\).

    ∎

    ▸ Corollary 8.4¶

    §8.3 ¶7¶

    원문

    s1 For every bounded permutation-invariant interaction law and bounded field law, with the functionals defined in Section 2,

    \[ \liminf_{N\to\infty}F_N\ge\inf_{r\ge0}\Phi_r. \]

    번역

    s1 유계이고 순열 불변인 모든 상호작용 법칙과 유계 field 법칙에 대해, Section 2 에서 정의한 functional 로 다음이 성립한다.

    물리 해석

    • s1 Corollary 8.4: lower bound \(\liminf F_N\ge\inf_r\Phi_r\) (유계 모형). §4 의 upper bound 와 합치면 Mézard–Parisi 공식. 짝수 \(p\) 나 (2.4) 가 필요 없다는 것이 중요. 📚 §8.3 ¶8

    식 Eq. §8.3 ¶7 #1 항별 표

    항 수학적 정의 지정된 물리 역할 하의 의미 검증
    \(\liminf F_N\ge\inf_r\Phi_r\) lower bound pressure 는 RSB Bethe 변분값 이상 📚 §8.3 ¶8

    (끝: s8-3-e7)

    ▸ Proof.¶

    §8.3 ¶8¶

    원문

    s1 Write \(A=\inf_{r\ge0}\Phi_r\), which is finite by (2.12).

    s2 Each encoded trial value is at least \(A\), so (8.1) gives, at every fixed \(L\),

    \[ A\le\underline F+2\varepsilon+ \limsup_{N\to\infty} \left|\Delta_N^{L,\mathbf u_{L,N}} -\mathcal B_{L-1}(\zeta_{L,N},\mathbf m^{(L)})\right|. \]

    s3 The inner limit uses that depth's selected sequence.

    s4 Letting \(L\to\infty\) in Proposition 8.3 gives \(A\le\underline F+2\varepsilon\), and then \(\varepsilon\downarrow0\) proves the result.

    번역

    s1 \(A=\inf_{r\ge0}\Phi_r\) 로 쓰며, 이는 (2.12) 에 의해 유한하다.

    s2 encode 된 각 시행 값은 적어도 \(A\) 이므로, (8.1) 은 모든 고정된 \(L\) 에서 다음을 준다.

    s3 안쪽 극한은 그 깊이의 선택된 수열을 쓴다.

    s4 Proposition 8.3 에서 \(L\to\infty\) 로 보내면 \(A\le\underline F+2\varepsilon\) 을 얻고, \(\varepsilon\downarrow0\) 으로 보내면 결과가 증명된다.

    물리 해석

    • s1–s4 논리: \(A\le\mathcal B(\zeta_{L,N})\) (inf 의 정의) \(\approx\Delta_N\) (Prop. 8.3) \(\le\underline F+2\varepsilon\) (선택). 🧭 물리 직관과의 차이: 물리에서는 정류점 방정식(population dynamics 의 고정점)을 풀어 그 값이 free energy 라고 하지만, 이 증명은 고정점을 전혀 쓰지 않는다 — 실제 계에서 읽은 order parameter 는 고정점일 필요가 없고, 그냥 inf 보다 크다는 것만 쓴다. ✅ 아래 전개
    전개: 부등식의 연결 (s2–s4)

    \(\zeta_{L,N}\in\mathcal M_L\), \(\mathbf m^{(L)}\) 은 허용 시행 → \(\mathcal B_{L-1}(\zeta_{L,N},\mathbf m^{(L)})\ge\Phi_{L-1}\ge A\) ✓. \(A\le\mathcal B\le\Delta_N+\lvert\Delta_N-\mathcal B\rvert\le\underline F+2\varepsilon+\lvert\Delta_N-\mathcal B\rvert\) ✓ ((8.1)). \(\limsup_N\) 후 \(L\to\infty\): (8.6) 으로 마지막 항 → 0 ✓.

    식 Eq. §8.3 ¶8 #1 항별 표

    항 수학적 정의 지정된 물리 역할 하의 의미 검증
    \(A\le\underline F+2\varepsilon+\limsup\lvert\Delta_N-\mathcal B\rvert\) 핵심 부등식 실제 계의 상태 구조는 하나의 시행 → inf 이상 ✅ 같은 문단 전개
