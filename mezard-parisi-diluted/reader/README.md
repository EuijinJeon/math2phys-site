# 문장번호 원문

`index.html`은 단독으로 열 수 있다. 초록 첫 문장부터 마지막 절까지 원문 순서로 `S0001`부터 번호를 매긴다. 수식 안의 소수점과 수식 뒤의 계속절은 분할하지 않는다. 절 제목과 정리 표제는 문장 수에서 제외하며, 그림 설명은 문장별로 센다. 참고문헌은 원래 인용번호를 쓴다.

## 질문과 답 추가

1. HTML에서 해당 문장번호나 식 번호를 찾고 `../../redesign/source/sections/`에서 앞뒤 문맥을 대조한다.
2. `annotations.json`에서 해당 문장번호의 질문 배열에 항목을 덧붙인다. 예시 형식은 다음과 같다.

   ```json
   {
     "S0001": [
       { "question": "여기서 even-arity는 어떤 가정인가요?", "answer": "원문에서 확인한 답을 여기에 작성한다." }
     ]
   }
   ```

   답에서 수식은 `\\( ... \\)` 또는 `\\[ ... \\]`로 감싼다.
3. 이 디렉터리에서 `python3 build.py`를 실행한다. 빌드에는 Python 3, BibTeX, Node.js와 KaTeX가 필요하다. 최초 한 번 `npm install`로 KaTeX를 준비하거나 `KATEX_PATH`로 설치된 모듈 경로를 지정한다. 완성된 HTML을 읽을 때는 설치 과정이 없다.

생성기는 저장소의 `redesign/source/main.tex`에서 초록과 입력 순서를 읽고, 해당 절의 TeX 및 `references.bib`를 사용한다. 유일한 삽화인 `figure1.png`는 배포 원문 PDF 26쪽 Figure 1에서 뽑았다. 수식은 HTML에 MathML로 포함한다. 원본 판본이나 문장 분할 규칙을 바꿀 때는 기존 주석의 대상도 대조한다.

문장 간 연결은 `inputs.json`에서 관리한다. 각 대상 문장번호 아래에 입력 문장번호와 연결 이유를 기록하면 빌드가 입력 목록과 역방향 출력 목록을 함께 생성한다.
