    The Mézard–Parisi formula for diluted spin glasses¶

    • 원문: OpenAI Math Release preprint (2026-09-23), 저자 OpenAI
    • 라이선스: 원문은 Apache License 2.0 (openai/math 저장소). 변경 사항: 이 문서는 원문 전체를 문장 단위로 나누어 번호를 붙이고, 한국어 번역과 물리 해석을 덧붙인 2차 저작물이다. 원문 내용은 고치지 않았다.
    • 기록: 역할 지정 · 용어집 · Q&A 기록 · 진행 상태
    읽는 법
    • 섹션 파일을 위에서부터 순서대로 읽는다. 각 파일 끝의 링크로 다음 섹션으로 간다.
    • 섹션마다 맨 위의 섹션 요약(접힌 블록)만 읽고 넘어가도 흐름이 이어지게 쓰여 있다.
    • 문단은 §3.2 ¶4, 문장은 s2, 식은 원문 번호 (3.4)(번호가 없는 식은 Eq. §3.2 ¶4 #1)로 부른다. 질문할 때 이 번호를 쓴다. 번호는 원문 기준으로 고정이고 바뀌지 않는다.
    • 문단은 원문 → 번역 → 물리 해석 → 식이 있으면 항별 표 순서다.
    • 검증 태그: ✅ 직접 전개로 확인 · 📚 출처 근거 · ❓ 미확인 · ⚠ 오류 의심 · 🔧 기술 단계(물리 대응 없음)
    • 제안 해석: 사용자가 아직 확정하지 않은 물리 역할에 따른 해석.
    • 🧭 물리 직관과의 차이: 물리 논증이 가정한 것을 수학이 따로 증명해야 했던 지점.
